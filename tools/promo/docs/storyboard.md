# 絵コンテとコピー

公開名称は **酒のしおり**（`sake-shiori.com`）。想定視聴者は、手持ちのボトルや飲んだお酒・感想を写真で残したい人。

未公開機能、料金、性能、利用実績は出さない。AI 読み取り・切り抜き・共有セラーは、この初版では紹介しない。
