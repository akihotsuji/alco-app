# 絵コンテとコピー

公開名称は **酒のしおり**（`sake-shiori.com`）。想定視聴者は、手持ちのボトルや飲んだお酒・感想を写真で残したい人。

未公開機能、料金、性能、利用実績は出さない。AI 読み取り・切り抜き・共有セラーは、この初版では紹介しない。

## 縦型動画（1080×1920 / 30fps / 約 30 秒 / 音声なし）

| 秒 | シーン | 見出し | 実画面 | 動き |
|---|---|---|---|---|
| 0〜3 | Hook | あのお酒、なんだっけ？ | 日別記録（写真付き） | 写真部分をゆっくり拡大 |
| 3〜10 | Register | 気になった一本を、写真で残す | 記録入力（写真付き） | フェード後、写真欄を拡大 |
| 10〜18 | Cellar | 手持ちのお酒が、自分だけの棚に | セラー棚 | 棚を大きく見せてゆっくり拡大 |
| 18〜25 | Notes | 飲んだ感想も、あとから振り返る | ノート一覧 | カードを大きく見せる |
| 25〜30 | End | お酒の記憶に、しおりを。 | マスコット＋サービス名＋URL | 短いフェード |

BGM・ナレーションは初版なし。字幕・見出しだけで内容が分かる。
