# 8-01 利用規約・プライバシーポリシー作成

| 項目 | 内容 |
|---|---|
| フェーズ | Phase 8 一般公開準備（将来・任意） |
| ステータス | **未着手** |
| 要件 | 一般公開時に利用規約・PP を整備。個人利用フェーズでは不要 |
| ソース | Phase 8 先頭 |

## 1. 概要

公開 Web アプリとして必要な法務文書と、アプリ内の表示・同意導線。文面の法的責任はオーナー（必要なら専門家）。エージェントは構成・実装フック・個人情報の棚卸しまで。

## 2. 前提条件

- Phase 7 で安定運用
- 収集データの棚卸し（アカウント、ログ、写真、IP は Cloudflare 側）

## 3. スコープ

**対象**

- 利用規約・プライバシーポリシーの草案と公開ページ
- サインアップ時の同意 UI
- 更新時の再同意が必要かは **要確認**

**対象外**

- 弁護士の確定意見の代替
- Cookie バナーの EU 完全対応（対象地域は **要確認**。まず日本）

## 4. 成果物

- `spec/legal.md` または `public/terms` のソース（Markdown）
- `/terms` `/privacy` ルート（認証なし公開。仕様に明記し承認）
- 同意の保存（user テーブルに timestamp。**要確認**）

## 5. 細分化タスク

1. データマップ（何を何の目的で）
2. 草案（酒類・20 歳、免責、データの国外移転 Cloudflare）
3. 公開ページ（テキストレンダリング）
4. サインアップにリンクとチェック
5. オーナー/専門家レビュー

## 6. 手順

実装は文面承認後。公開エンドポイントとして api-design / 画面仕様を更新する。

飲酒ログは要配慮になりうる健康隣接データ。PP に「健康データの取扱い」をどう書くか専門家。**要確認**。

## 7. 仕様詳細

最低含める論点（法務確定ではない）:

- 事業者（個人名 or 屋号）**要確認**
- 20 歳未満利用禁止
- データの保存場所（Cloudflare）
- 削除請求の方法（個人公開でも）
- 写真の権利（ユーザーが写した瓶）

## 8. 受け入れ条件

- [ ] 公開ページがある
- [ ] サインアップから辿れる
- [ ] 文面がオーナー承認
- [ ] 公開ルートが仕様に明記
- [ ] 監査（公開でも XSS なし、秘密なし）

## 9. セキュリティ観点

- 静的ページでもヘッダー付与
- 同意チェックをクライアントだけで迂回できない（サーバーで必須）
