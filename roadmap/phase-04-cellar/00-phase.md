## 目的

手持ちボトルの在庫管理と、写真アップロード基盤（R2）を構築する。写真基盤は Phase 5 でも再利用する。

## 依存

- Phase 2 完了（認証、API 基盤、レイアウト）
- Phase 0-03 で R2 バケット（dev）が作成済みであること
- Phase 3 完了は必須ではないが、ドッグフードと並行するなら Phase 3-07 の後が安全
- 実装前に `spec/features/cellar.md` を承認する

## ゴール（フェーズ DoD）

- 手持ちのボトルを写真付きで登録・検索・状態管理できる
- 写真が R2 に保存され、他ユーザーからアクセスできないことがテストで担保されている
