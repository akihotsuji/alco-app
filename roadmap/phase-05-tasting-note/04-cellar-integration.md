# 5-04 セラー連携

| 項目 | 内容 |
|---|---|
| フェーズ | Phase 5 テイスティングノート |
| ステータス | **未着手** |
| 要件 | ボトル詳細からノート一覧、ノート作成時のボトル選択 |
| ソース | Phase 5 セラー連携 |

## 1. 概要

2 コア機能をつなぐ。v1.x の「開栓したら記録も作る」はまだやらない。

## 2. 前提条件

- 5-02、ボトル詳細（4-02）
- GET /api/tasting-notes?bottleId=

## 3. スコープ

**対象**

- ボトル詳細のノート一覧（新しい順）と「ノートを書く」
- ノート作成のボトルピッカー（検索、未選択可）
- ノート詳細からボトル詳細へのリンク（bottle があるとき）

**対象外**

- 飲酒記録同時作成
- 双方向の複雑なグラフ UI

## 4. 成果物

- UI 導線
- API が未なら `bottleId` クエリ
- テスト: 他人のボトル ID で一覧は空または 404（仕様: ボトルが他人なら 404 推奨。存在漏洩防止）

## 5. 細分化タスク

1. ボトル所有確認の共通ヘルパ
2. 詳細埋め込み
3. ピッカー（ボトル多いときの検索）
4. 削除済みボトル: ノートは残しリンク切れ表示。仕様同期
5. テストと監査

## 6. 手順

ブランチ: `feature/note-bottle-link`

ピッカーは `/api/bottles?q=` を再利用。飲み切りを含めるかは **要確認**（テイスティングは飲み切り後も書く）。

## 7. 仕様詳細

- ボトル詳細のノートは同じ user のみ（常に自分）
- 「ノートを書く」で bottleId を query に乗せて作成画面を開く
- 作成画面でボトル変更可

## 8. 受け入れ条件

- [ ] ボトルからノート一覧と作成ができる
- [ ] 作成時にボトルを選べる
- [ ] 他人 bottleId で 404
- [ ] MVP 3 機能が実機でつながる（Phase 5 DoD の一部）
- [ ] DoD 5 項

## 9. セキュリティ観点

- URL `?bottleId=` を信用せずサーバーで所有確認
- クライアントがボトル名だけ出して ID を取り違えない
