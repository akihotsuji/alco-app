# 3-05 日別ビュー（一覧・合計・編集・削除）

| 項目 | 内容 |
|---|---|
| フェーズ | Phase 3 飲酒記録 |
| ステータス | **完了**（2026-09-06） |
| 要件 | 日別: 杯数・純アルコール量。記録の編集・削除 |
| ソース | Phase 3 日別ビュー |

## 1. 概要

指定日（デフォルト今日、JST）の記録一覧と合計。編集・削除。**ホームから入る閲覧・編集の画面**（中央タブの着地ではない。2026-09-06 オーナー確定 (c)）。入口はホームの今日カード（今日）/ 週マス（その日）/ `log-new` `log-edit` の保存後（`?highlight=`）/ 週サマリーの日別行（[spec/screen-designs/03-log.md](../../spec/screen-designs/03-log.md) `log-day`）。

## 2. 前提条件

- 3-02 の作成 API（`GET` / `DELETE /api/drink-logs/:id` は 3-02 済み）
- 3-03 のホーム導線（今日カード → `/logs`、週マス → `/logs/:date`）と中央タブの撮影開始への切替（`/logs` 配下の親タブはホーム）
- [alcohol-calculation.md](../../spec/features/alcohol-calculation.md) の日付境界（**Asia/Tokyo**。2026-08-13 確定）

## 3. スコープ

**対象**

- GET 一覧（from/to または date クエリ。`thumbPhotoId`・`bottleId`・`drinkName` を含む）
- PATCH / DELETE
- UI: 日送り、合計（0 件は休肝ピル）、行（写真サムネ 48px / 種類アイコン、ボトル名）、`?highlight=` の挿入 + 2 秒強調、保存後トーストの「取り消す」、編集フォーム（`log-edit`）、削除確認。**「記録する」「カメラ」「マイドリンクチップ」は置かない**（ホームに集約。D3〜D5 は欠番）
- 空状態（休肝の日。キャラ・ボタンは出さない。全期間 0 件の初回だけ X7 の文言「中央の記録ボタンから写真を撮って記録できます」）
- モーション（[spec/motion-design.md](../../spec/motion-design.md) 10 章）: `useHighlightRow`（行の挿入 M-14、リングのフェード M-15、`scrollIntoView` M-16。X1。`log-new` / `log-edit` の保存後で使う）、保存後トーストの取り消しで消える行の inset → フェード（X2）と合計のカウント（M-09）・休肝ピル（M-18）。X3 は廃止

**対象外**

- 週月グラフ（3-06）
- 他ユーザーの日次

## 4. 成果物

- API GET/PATCH/DELETE
- 日別画面
- テスト: 自分の行だけ、他人は 404、削除確認

## 5. 細分化タスク

1. GET を日付でフィルタ（サーバー側。TZ は JST の日の始まり〜終わりを UTC に変換）
2. PATCH は Zod 部分更新。alcohol_g 再計算
3. DELETE は id+userId
4. UI
5. 認可テスト 404
6. 監査

## 6. 手順

ブランチ: `feature/drink-log-daily`

日付処理は shared に `jstDayRange(isoDate)` を置きテストする（計算以外のロジックもテスト対象）。

削除は誤操作が多い。仕様の確認ダイアログに従う。

```powershell
pnpm test && pnpm lint && pnpm typecheck
```

## 7. 仕様詳細

- 合計杯数 = 行数（1 行 1 杯）
- 合計 g = 行の計算値合計
- 編集で種類を変えたときプリセット上書きかは 3-01 に従う
- 存在しない id と他人の id はどちらも 404
- 日付の移動は **前日 / 翌日の日送りのみ**（D1。カレンダーピッカーは置かない。drink-log.md 9 章で確定）。任意日はホームの週マス / 週・月サマリーの行から
- ヘッダー左右は日送りに使うため戻るボタンは置かない。戻りは履歴（無ければ `/`）。ホームタブが現在地なのでタブでも戻れる
- 過去日に記録したいときは `log-new` の日時行で日付を変える（日別に記録ボタンは無い）

## 8. 受け入れ条件

- [x] 当日の一覧と合計が見える
- [x] 編集・削除ができる
- [x] 他ユーザー 404 テスト
- [x] 空状態がある（キャラ・ボタンなし。初回だけ X7 の文言）
- [x] 日別に「記録する」「カメラ」「マイドリンク」が無い。ホームの今日カード / 週マス / 保存後 / 週サマリーの行から入れ、タブバーの現在地はホーム
- [x] 保存後の `?highlight=` で行が挿入され、「取り消す」で行が inset → フェードで消える（X1 / X2）
- [x] DoD 5 項

## 9. セキュリティ観点

- 削除条件は id 存在確認だけにしない
- メモ編集も XSS なし
- クエリ `from` `to` を Zod で ISO 日付に制限（SQL インジェクション不可でも異常値で全件取得しない）
