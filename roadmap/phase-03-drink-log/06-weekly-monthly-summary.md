# 3-06 週/月サマリー（グラフ・休肝日）

| 項目 | 内容 |
|---|---|
| フェーズ | Phase 3 飲酒記録 |
| ステータス | **完了**（2026-09-06） |
| 要件 | 週別/月別推移グラフ、休肝日数 |
| ソース | Phase 3 週/月サマリー |

## 1. 概要

期間の純アルコール推移と休肝日数を出す。チャートは軽量ライブラリ。目標設定は v1.x なので「上限線」は出さない。ホーム配下（親タブはホーム）。入口はホームの今日カード内「今週 ›」（H13。3-03 でリンクを置く）→ 週サマリー → ヘッダー右「今月 ›」→ 月サマリー。月の週行 → 週、週の日別行 → その日の `log-day`（[spec/screen-designs/02-home.md](../../spec/screen-designs/02-home.md) `summary-week` / `summary-month`）。

## 2. 前提条件

- 3-05 の一覧 API または専用 summary API
- 3-03 のホーム（「今週 ›」リンクの置き場。今日カード本体は日別へ行くため、週への入口はこのリンク）
- [spec/features/alcohol-calculation.md](../../spec/features/alcohol-calculation.md) の休肝定義
- デザインシステム

## 3. スコープ

**対象**

- 週ビュー、月ビュー
- グラフ（日ごとの g）

**対象外**

- 種類別内訳（将来構想）
- CSV エクスポート

- チャートコンポーネント

3. 集計関数のテスト

5. UI（モバイルで横スクロールしすぎない）

```powershell

```

Lighthouse は Phase 6。ここでは明らかに重い lib を避ける。

## 7. 仕様詳細

- 休肝日数: 期間内の **Asia/Tokyo** カレンダー日のうち、ログ 0 の日（0g 記録がある日は休肝にしない）
- 未来の日は `isFuture` とし、休肝に含めない（1-05 / 1-06 確定）
- 週: アンカー日を含む ISO 週、**月曜始まり**（JST。1-05 / 1-06 確定）

グラフ a11y: 数値テーブルを併記するか、aria ラベル。Phase 6-04 でも可。今は合計数字をテキストで出す。
