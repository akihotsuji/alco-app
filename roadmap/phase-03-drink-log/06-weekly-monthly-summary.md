# 3-06 週/月サマリー（グラフ・休肝日）

| 項目 | 内容 |
|---|---|
| フェーズ | Phase 3 飲酒記録 |
| ステータス | **未着手** |
| 要件 | 週別/月別推移グラフ、休肝日数 |
| ソース | Phase 3 週/月サマリー |

## 1. 概要

期間の純アルコール推移と休肝日数を出す。チャートは軽量ライブラリ。目標設定は v1.x なので「上限線」は出さない。

## 2. 前提条件

- 3-05 の一覧 API または専用 summary API
- 1-06 の休肝定義
- デザインシステム

## 3. スコープ

**対象**

- 週ビュー、月ビュー
- グラフ（日ごとの g）
- 休肝日数の数字
- 軽量チャート依存の追加（PR に理由）

**対象外**

- 種類別内訳（将来構想）
- CSV エクスポート
- 目標達成

## 4. 成果物

- summary API または既存 GET の集計
- サマリー画面
- 集計の単体テスト（休肝日カウント）
- チャートコンポーネント

## 5. 細分化タスク

1. ライブラリ選定（例: uPlot, lightweight charts, Recharts。バンドルサイズを見る。**要確認**）
2. 週の始まりは **月曜（ISO 8601）**（1-05 確定。覆す場合は `spec/api-design.md` を先に直す）
3. 集計関数のテスト
4. API
5. UI（モバイルで横スクロールしすぎない）
6. 監査（依存追加）

## 6. 手順

ブランチ: `feature/drink-summary`

集計はサーバー推奨（改ざん耐性、転送量）。クライアント集計にするなら生データ期間を制限する。

```powershell
pnpm test
```

Lighthouse は Phase 6。ここでは明らかに重い lib を避ける。

## 7. 仕様詳細

- 休肝日数: 期間内の **Asia/Tokyo** カレンダー日のうち、ログ 0 の日
- 未来の日は月ビューで「まだ来ていない」として休肝に含めない。**要確認**
- 週: 今日を含む 7 日 vs カレンダー週。**要確認**（週の始まり。日付境界自体は JST で確定済み）

グラフ a11y: 数値テーブルを併記するか、aria ラベル。Phase 6-04 でも可。今は合計数字をテキストで出す。

## 8. 受け入れ条件

- [ ] 週と月で推移と休肝日数が見える
- [ ] 集計テストがある
- [ ] 依存理由が PR にある
- [ ] モバイルで操作できる
- [ ] DoD 5 項

## 9. セキュリティ観点

- summary も userId スコープ
- 他人の期間をクエリで指定できない（userId をクエリに持たない）
