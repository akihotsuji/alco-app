## 回帰シナリオ

1. ログイン → 写真なし記録 → マイドリンク → 日 / 週 / 月確認
2. 中央タブ → 撮影 → 編集 → 写真付き記録 → 編集 / 削除
3. セラー追加 → 切り抜き → ラベル認識 → 棚 → 詳細 → 開栓 → undo / 復元
4. セラー追加 → 記録でボトル選択 → ボトル詳細から記録参照
5. ノート作成 → 写真6枚 → ボトル選択 → 一覧 → 詳細 → 編集 / 削除
6. 貯蔵庫のボトル → ノート作成 → ボトル詳細のノート節
7. 各写真用途で撮影キャンセル、撮り直し、通信失敗、アップロード再試行
8. 戻る、再読み込み、セッション再開、ライト / ダーク、動きを減らす
