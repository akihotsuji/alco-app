# 初回ガイド

2026-09-08 オーナー指示。目的は全機能の説明ではなく、次の理解を短時間で得てもらうこと。

- 飲んだ量を残すのが「記録」
- 持っているボトルを管理するのが「セラー」
- 味や感想を残すのが「ノート」
- 写真やボトル関連付けは、必要なときだけ使える
- まず一つの操作ができれば、そのまま使い始められる
- 初回は記録だけ案内し、セラー／ノートは設定の「使い方を見る」から同じ手順で試せる

見れば分かるボタンを順番に読み上げるツアーは作らない。タイマーだけで進めない。説明を読ませるために操作を待たせない。保存までの各操作はスポットライトで示す。

画面の正本は [screen-designs/08-first-run-guide.md](../screen-designs/08-first-run-guide.md)。

## 1. 設計表

| 時点 | ユーザーがその時点で疑問に思うこと | 説明する一文 | 案内対象の実操作 | 次へ進む条件 | スキップ・終了時の挙動 |
|---|---|---|---|---|---|
| 初回ホーム（データなし） | 何から始めればよいか。全部使わないと始まらないのか | 使い方を少し試してみますか？ | 「操作を試す」「今はしない」 | 「操作を試す」でホームの記録ボタンへ | 「今はしない」またはシートを閉じる。`skipped` をユーザー単位で記憶。実データは変えない。以後は自動表示しない |
| 記録 1/3 ホーム | 飲んだ量はどこに残すのか | 飲んだ量は、ここから残せます | ホーム H8「お酒を記録する」を実際にタップ。画面を暗くし H8 だけを切り抜いて枠で示す（スポットライト） | ユーザーが H8 をタップしたときだけ練習フォームへ | 「ガイドを終了」で `skipped`。H8 以外（写真から記録・中央タブ・カメラ）はガイド中は本番の撮影・保存へ進まない |
| 記録 2/3 量 | 写真が必要か。次に何をすればよいか | 量を選ぶ。写真はなくても大丈夫です | 練習フォームの量欄をスポットライト。量チップまたは数値を変える | 量を変えたとき保存ボタンへ進む | 戻る・再読込・途中終了でも保存 API / 写真 / 認識 / 集計 / 開栓は呼ばない。本番の下書きは消さない |

| 記録のあと | 他にも必須の操作があるのか。セラーやノートは？ | 記録の基本はこれだけです。セラーやノートは、設定の「使い方を見る」から試せます | 「ガイドを終了」「ほかの使い方を見る」 | 終了で `completed`。ほかの使い方は設定の扇メニューへ | 練習値は本番フォーム・マイドリンクへ持ち込まない。キャラは短く 1 回ウィンク |

| セラー 2/3 種類 | 何を選べばよいか | 種類を選ぶ。写真があれば色や泡から推測します | 種類チップをスポットライト | 種類を変えたとき保存へ | 練習中は保存 API / 写真 / 認識なし |
| セラー 3/3 保存 | 棚に残るか | 練習として並べる。棚には残りません | 練習保存をスポットライト | 練習保存をタップ | 完了シート。実データは変えない |
| ノート 1/3 作成 | ノートは記録と何が違うか | 味や感想は、ノートに残します | 空状態の「ノートを作成」または右下 FAB をスポットライト | 作成をタップしたときだけ練習フォームへ | 「ガイドを終了」で `skipped`。本番の作成へ進まない |
| ノート 2/3 評価 | 何を書けばよいか | 星で評価する。写真はなくても大丈夫です | 評価欄をスポットライト | 評価を変えたとき保存へ | 練習中は保存 API / 写真 / 認識なし |
| ノート 3/3 保存 | ノートに残るか | 練習として保存する。ノートには残りません | 練習保存をスポットライト | 練習保存をタップ | 完了シート。実データは変えない |
| セラー / ノート初回（空・ガイド外） | その画面は何をする場所か | 上表と同じ一文 | 既存の空状態に 1 行だけ足す | 画面を見た時点で案内済み。追加は任意 | 独立ツアーは出さない。1 回だけ。スキップ専用ボタンは足さない |

セリフは一度に 1〜2 文。文字は一括表示（タイプ演出なし）。マスコットは案内時に対象を見る、操作後にこちらを見る、終了時に短くウィンクする。

## 2. 記憶と対象

| 項目 | 決定 |
|---|---|
| 保存先 | `localStorage` `guide.first-run`。キーに `userId` を含め、端末内でユーザー単位 |
| 状態 | `unset` / `skipped` / `completed` / `existing` |
| 自動表示 | `unset` かつ、飲酒記録・マイドリンク・ボトル・ノートがすべて 0 のときだけ招待を出す |
| 既存ユーザー | いずれかの実データがある場合は `existing` を静かに書いて自動開始しない |
| 再実行 | 設定「操作 › 使い方を見る」。タップで扇メニュー（記録 / セラー / ノート）。選んだ機能のスポットライトから始める。招待は省略 |
| セラー / ノート初回 | 同じ JSON の `cellarHintSeen` / `notesHintSeen`。空状態を見たときに立てる（ガイドツアーとは別） |

サーバー API・設定画面の健康項目は増やさない。

## 3. 練習の禁止事項

練習中は次を実行しない。

- `POST /api/drink-logs` ほか保存 API
- 写真取得・権限要求・`photo-edit`
- 認識 API
- 集計の更新
- 開栓 / 復元
- マイドリンクへの書き込み
- ボトル / ノートの作成

常に「練習中・保存されません」を出す。本番の「記録を保存」を見せて無効化するだけにしない。練習専用の保存操作にする。
