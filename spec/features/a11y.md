# アクセシビリティ（最低限）

実装: Phase 6-04。要件は [01-requirements.md](../01-requirements.md) 非機能「アクセシビリティ」、手順は [roadmap/phase-06-pwa-quality/04-accessibility.md](../../roadmap/phase-06-pwa-quality/04-accessibility.md)。色の比は [design-system.md](../design-system.md)、動きは [motion-design.md](../motion-design.md) 6.8 / 10.5 / 10.6。

- 状態: **本 PR で追加**（6-04 実行。WCAG 完全準拠・スクリーンリーダー全フローは対象外）
- Lighthouse 点数は変動する。根拠は日付付きで本ファイルと PR に残す

---

## 1. 目的

スマートフォンで困らない最低限。ラベルなし入力、薄い灰色の本文、小さすぎるアイコンボタン、動きを止められない演出を潰す。点数の目安は Lighthouse モバイル a11y **80+**（Phase 6 DoD）。

---

## 2. 方針（6-04 の確定）

| 項目 | 決定 | 理由 |
|---|---|---|
| 準拠レベル | WCAG 2.2 の **最低限**（本文 4.5:1、ラベル、名前、フォーカス、reduced motion） | 専門監査は対象外 |
| Lint | **Biome の a11y 推奨ルール**を明示する。`eslint-plugin-jsx-a11y` は入れない | 既存は Biome のみ（[02-tech-stack.md](../02-tech-stack.md)）。jsx-a11y と重複する |
| Lighthouse CI | **入れない** | 6-03 と同じ。無料枠・フレーク。手動 + 本ファイルの記録 |
| 計測ルート | 計測専用ルートは作らない | 認可を外さない。未ログインは `/login`、認証後は通常の `/` |
| チップ高さ | **40px のまま**（[00-common.md](../screen-designs/00-common.md) 2.6） | ラベル付きで横幅は 44 を超える。アイコンのみを 44 にする |
| ヘッダー円ボタン | **44px**（`--tap-min`） | 設計は旧 40px。6-04 で tap-min に揃える |
| 星評価 | `radiogroup` + `radio`。数値欄は従来どおり | タスク「ラジオグループかスライダーで名前付け」 |
| innerHTML | a11y 目的でも使わない | XSS と分離。テキストと属性だけ |

## 4. フォーム

ログイン・登録・記録・マイドリンク・ボトル・ノートの入力は、**見えるラベル**または `aria-label` を持つ。placeholder だけにしない。

エラーは `aria-invalid` とテキスト（`role="alert"`）。可能なら `aria-describedby` で入力と結ぶ。

削除確認の主ボタンは「ログアウト」「削除する」など **何をするか**が名前に入る。

---

## 5. フォーカス・モーダル

- フォーカスリングは `2px solid var(--ring)`、オフセット 2px。`outline-none` のまま放置しない（`:focus-visible` で戻す）
- shadcn / Radix Dialog はフォーカストラップを使う
- 自作モーダル（`photo-edit`、ノート写真ビューア）は `useFocusTrap` で Tab を閉じる
- 保存後の日別到着ではフォーカスを **ヘッダーの日付**（`#app-header-title`）に置く。挿入行に `aria-live` は付けない（[motion-design.md](../motion-design.md) 10.5）
- 統計や補足が見えるリンクに短い `aria-label` を付けない（今日カード・日別行。名前は見える文字から作る）

---

## 6. 色・状態

本文・muted・主ボタン・休肝・danger の比は design-system の表が正。計算は `src/shared/contrast.ts`。水位線中も 4.5:1（`--fill-tint`）。

リンクの見える文字は accessible name に含める。短い `aria-label` で統計を上書きしない（今日カード・日別行）。

色だけにしない:

| 状態 | 文字または名前 |
|---|---|
| ボトル棚 / 貯蔵庫 | ピル「セラー」「貯蔵庫」 |
| ホーム今日 | 「記録あり」「未記録」 |
| 週マス | `aria-label` に杯数または「記録なし」。凡例あり |
| AI 先埋め | ピル「AI」 |

1 秒 3 回以上の明滅は作らない。スピナー以外に `animation-iteration-count: infinite` を置かない。

## 7. reduced motion

OS の `prefers-reduced-motion: reduce` または設定「動きを減らす = 常に減らす」で `<html data-reduce-motion="1">`。

| 残す | 止める |
|---|---|
| 不透明度フェード ≦150ms（トースト・行の出現・ダイアログ） | 移動・拡縮・水位線・棚板ハイライト・キャラの `pour` / まばたき |
| 色・影の即時切替 | `scrollIntoView` / `scrollTo` の smooth |
| トースト `role="status"` | 挿入行の `aria-live` |

情報は文言・色・形で残る（P7）。
