# キャラクター（マスコット）仕様

Phase 1-08 の成果物。ニューモーフィズムだけでは素っ気ないため、**1 体のキャラクター**でポップさを足す。見た目・ポーズ・置き場所・写真合成のルールの正本。配色や影は [design-system.md](design-system.md)、画面ごとの配置は [screen-designs/](screen-designs/README.md)。

- 状態: **オーナー承認済み**（2026-09-06。名前は付けない）
- アセット: [assets/character/](assets/character/)（SVG 4 ポーズ）
- 実装: Phase 2-06 で `<Mascot pose size />` コンポーネントとして `src/client` に置く

## 1. 決定事項（レビュー対象）

| 項目 | 決定 | 理由 |
|---|---|---|
| モチーフ | **赤ワインが注がれたワイングラス**に、大きな白目＋黒目の「目」が付いたキャラクター | オーナー指示。ワイン主体のプロダクトと一致 |
| 目の作法 | 白目 2 つ（右をやや大きく、少し重ねる）、黒目は小さめ、白いハイライト 1 点。口は描かない | 参考画像「Nani!?」の驚き顔。目だけで感情を出す |
| 驚きマーク | 左上に 3 本線の閃き。リム角から放射し、中央を長くする | 参考画像の記号。短いと 72px 以下で点に潰れる |
| 名前 | **付けない**（2026-09-06 オーナー決定）。UI 文言・spec・コードのいずれにも固有名を出さない。コード上の識別子は `Mascot` | 名前を出すとキャラクター語りになり五月蠅い |
| 体数 | **1 体のみ**。仲間・敵・進化は作らない | ゲーミフィケーション薄めの方針（design-system 原則 4） |
| 役割 | 反応する相棒。**説明・誘導・広告はしない** | ラベルの代わりに使わない。テキストが正 |
| 飲酒の助長 | **「もう一杯」「飲もう」等の誘いは絶対に出さない** | 酒類アプリの責任。休肝日を肯定する側に立つ |
| モーション | 保存成功のほか、短いまばたき・登場時の視線・タップ／完了のウィンクを許可。待機の揺れ・ジャンプは禁止。口・手足・新キャラ・育成は作らない | [motion-design.md](motion-design.md) 6.6（2026-09-08 改訂）。reduced motion で無効 |
| 写真合成 | 記録・ノートの写真は **右下に 4 ポーズのいずれか**を合成できる（編集画面オープン時に抽選。既定 ON、保存前に OFF 可。背後グローは敷かない）。セラー写真には合成しない | 2026-09-08。白い丸が見えるのをやめ、記録に反応している感じを出す。ポーズは増やさない |
| 描画方式 | インライン SVG（React コンポーネント）。ラスタ画像は持たない | テーマ追従（線色 `currentColor`）、拡縮自由 |
| アプリアイコン | 「通常」ポーズをライト地の正方形に載せる。角丸は OS が付ける。ビルド時に PNG 化（6-01。[features/pwa.md](features/pwa.md)） | ホーム画面追加時の識別。primary 地だとワインと溶ける |

## 2. 造形

viewBox `0 0 120 160`。比率は 3:4。

```
        ✧  ｜ ﾞ         ← 閃き（驚きポーズのみ、左上）
     ┌──────────┐
     │  ◯  ◯  │       ← 白目 2 つ（右が大きい、少し重なる）。黒目は内寄り
     │▓▓▓▓▓▓▓▓▓▓│       ← 赤ワイン（ボウルの下 45%。ポーズで水面が動く）
      ╲▓▓▓▓▓▓▓▓╱
         ││              ← ステム
       ──┴┴──            ← フット
```

| 部位 | 値 |
|---|---|
| 線 | `currentColor`、太さ 3（viewBox 単位）。テーマで自動反転（ライト `--foreground`、ダーク `--foreground`） |
| ボウル | `#FFFFFF` 35% 透明。左にハイライト 1 本（白 70%） |
| ワイン | `--mascot-wine` `#8E2F3C`、水面のハイライト `--mascot-wine-light` `#B34A5A`。**テーマで変えない**（本物の赤） |
| 白目 | `#FFFFFF` 塗り、線は `currentColor` |
| 黒目 | **固定** `#1F1B17`（ダークで `currentColor` にすると白目に溶ける） |
| 最小表示 | 高さ **32px**。それ以下では使わない（目が潰れる） |
| 標準表示 | ホーム 72px、空状態 96px、ログイン 120px、トースト 32px、写真合成は写真短辺の 22% |
| セーフエリア | 周囲に高さの 10% 以上の余白。ボタン・文字に重ねない |

色トークンは [design-system.md](design-system.md) の「キャラクター」節に追加。primary（UI のワイン色）とは意図的に別の値にする（キャラのワインは UI 色より一段深い）。

## 3. ポーズ

| ID | ファイル | 目 | ワイン | 付属 | 用途 |
|---|---|---|---|---|---|
| `default` | [mascot-default.svg](assets/character/mascot-default.svg) | 正面、黒目は内寄り | 水平 | なし | ホーム（記録あり）、ログイン、設定 |
| `surprised` | [mascot-surprised.svg](assets/character/mascot-surprised.svg) | 見開く、黒目は小さく **左上**を見る | 傾いて跳ねる（滴 2） | 閃き 3 本 | **写真合成の標準**、写真編集画面、セラーの空状態 |
| `rest` | [mascot-rest.svg](assets/character/mascot-rest.svg) | 閉じる（︶） | 少なめ | z z | ホーム（未記録）、週マスの休肝日ツールチップは使わない |
| `cheer` | [mascot-cheer.svg](assets/character/mascot-cheer.svg) | 細め、黒目は上 | 揺れて盛り上がる | 星 2 | 保存成功トーストの左端、1 タップ記録直後の 300ms |

ポーズは 4 つで凍結する。増やすときは本ファイルを更新しオーナー承認。

`surprised` の視線は **左上固定**。写真の右下に置いたとき、被写体（中央〜左上）を見る構図になる。左下に置く用途は作らない。

## 5. 写真合成（スタンプ）

記録・ノートの写真に、右下へ 4 ポーズのいずれかを焼き込む。**クライアントの Canvas で合成し、合成後の JPEG を 1 枚だけ保存する**（元画像は保存しない。R2 と無料枠を倍にしない）。

| 項目 | 値 |
|---|---|
| ポーズ | `default` / `surprised` / `rest` / `cheer` の 4 つ。**編集画面を開いたときに 1 回抽選**し、プレビューと保存で同じポーズを使う。撮り直し（同じオープン）では据え置き。新しいポーズは足さない |
| 大きさ | 写真の **短辺 × 0.22**（高さ基準。幅は比率 3:4 で決まる） |
| 位置 | 右下。右・下の余白は短辺の **4%** |
| 縁 | **グローは敷かない**。SVG をそのまま合成する（白い楕円が見えるのを避ける） |
| 線色 | 合成時は **常にライトの線色** `#2B261F`（写真は明るいことが多い。テーマ非依存） |
| トグル | 設定画面 S3 のみ。**既定 ON**。酒記録は撮影ごとに選ばない。ノートの編集画面は設定どおりプレビューする |
| セラー写真 | 合成 **不可**（トグル自体を出さない） |
| 被写体 | 写真本体に色補正は掛けない。AI 用画像にもキャラを入れない |
| 保存形式 | JPEG、長辺 1280、品質 0.82。Canvas 再エンコードで **EXIF（位置情報含む）は落ちる** |

合成は `src/client` の純粋関数（`composeMascot(canvas, pose, opts)`）にし、位置・大きさの計算は単体テストで固定する。

## 6. モーション

正本は [motion-design.md](motion-design.md) 6.6「character usage」と M-25（2026-09-06 承認）。ここでは一覧だけ。時間はモーショントークン（`--dur-state` 200ms、`--dur-fill` 400ms）。

| 場面 | 内容 | 時間 |
|---|---|---|
| ポーズ切替（default ↔ rest、→ cheer） | クロスフェード | `--dur-state` 200ms |
| 1 タップ記録直後（ホーム 72px） | cheer に切替 → 300ms 後 default。切替の瞬間に **上 4px → 0 を 1 回**（`--dur-state`）。水面は上げない（トースト側が担う） | 合計 500ms |
| 保存成功トーストの cheer 32px | **水面が 45% → 60% に 1 回上がる**（`pour`）。目・星・輪郭は動かさない | `--dur-fill` 400ms |
| 空状態の 96px | マウント時に不透明 0 → 1、上 8px → 0 を 1 回（M-26）。以後静止 | `--dur-enter` 240ms |
| 写真編集でトグル ON | キャラが右下から 8px スライドイン | `--dur-state` 200ms |
| まばたき（M-33） | 両目を短く閉じて開く。待機は 15〜30 秒間隔 | 120〜180ms |
| 視線（M-34） | 登場時に一度、対象からユーザー側へ | 200〜300ms |
| ウィンク（M-35） | タップ時または操作完了時に短く 1 回。クールダウンあり | 300〜450ms |
| 保存反応（M-36） | 小さく上下し、視線・表情が変わる | 300〜500ms |
| 休息 | `rest`。目を閉じて落ち着いた姿勢 | — |
| 多量プレビュー（M-38） | 傾き + 少量のしずくのあと静止。自動表示条件は未確定 | 状態変化時だけ |

- 待機アニメは短いまばたきだけ。揺れ・ジャンプ・ランク・報酬・再生ボタンは置かない
- 画面外・バックグラウンドでは停止。同じ画面で動くキャラは 1 体
- タップは装飾のみ。押さなくても全機能が使える
- 追加記録のたびに倒れ直さない。エラー表示と混同しない。酔い・体調の判定には見せない
- 「飲み過ぎ」閾値は作らない。ユーザー設定上限は未実装のため自動表示しない（`?mascotPreview=heavy` で確認）
- 日付変更・編集・取り消しで姿勢を再計算する。量が分からない状態を元気・安全と断定しない
- reduced motion ではまばたき・ウィンク・傾き・液面を止め、静止で情報を伝える
- 既存 SVG を部位ごとに扱い、CSS / SVG アニメーションだけ使う
- 効果音なし。触感はキャラの動きに同期させない

## 7. 禁止

- 2 体目のキャラクター、表情差分の追加（4 ポーズで凍結）
- 吹き出しでの会話文。空状態の文言はテキストブロックとして置き、キャラは添えるだけ
- 飲酒を促す文脈での使用（「乾杯しよう」「あと 1 杯で…」）
- ラスタ画像（PNG）の直置き。アプリアイコンだけ Phase 6-01 でビルド時に生成（`public/pwa/`。gitignore。ソースは `mascot-default.svg` + ライト `--background`）
- ボタン・入力・ラベルの上に重ねる。タップ領域を侵さない
- ユーザーによる色・ポーズのカスタマイズ

## 8. アセットとコンポーネント（Phase 2-06）

```
spec/assets/character/mascot-{default,surprised,rest,cheer}.svg   ← 仕様の正本
src/client/components/mascot/Mascot.tsx                           ← 4 ポーズをインライン SVG で持つ
src/client/components/mascot/compose-mascot.ts                    ← Canvas 合成の純粋関数
```

```tsx
<Mascot pose="default" size={72} />            // 高さ px。幅は 3:4 で自動
<Mascot pose="rest" size={72} aria-hidden />   // 装飾のときは aria-hidden
<Mascot pose="cheer" size={32} pour aria-hidden />  // 水面が 45% → 60% に 1 回上がる（M-25。cheer 以外では無視）
```

- `color` は親の `color`（`currentColor`）を継承。テーマで線色が変わる
- `pour` は `cheer` のときだけ有効。水面のパスを 2 段（45% / 60%）持ち、上段を CSS `clip-path` で `--dur-fill` に出す。SMIL `<animate>` は使わない。reduced motion では上段を即時表示
- 装飾用途は `aria-hidden`。意味を持たせる場面は作らない（テキストが常にある）
- SVG の `<clipPath id>` はコンポーネント内で `useId()` により一意化する（同一画面に複数出しても衝突しない）

ホーム追加用。仕様の正本は [features/pwa.md](features/pwa.md)。

|---|---|
