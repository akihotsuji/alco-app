## `guide-home-record` 記録ボタン

ホームの上にスポットライトを重ね、H8 だけを操作対象として示す。ボタン一覧の読み上げはしない。

```
┌──────────────────────────────────┐
│ ░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░ │  画面を暗くする（H8 以外）
│ ░  [ + お酒を記録する ]  ░░░░░░░ │  H8 を切り抜き + primary の枠
│ ░  ┌ 吹き出し ──────────────┐ ░ │
│ ░  │ 🍷 飲んだ量は、ここから  │ ░ │
│ ░  │    残せます             │ ░ │
│ ░  │ 1 / 2    ガイドを終了   │ ░ │
│ ░  └────────────────────────┘ ░ │
└──────────────────────────────────┘
```

| # | 要素 | 種別 | 内容・挙動 |
|---|---|---|---|
| G3 | 一文 | テキスト | 「飲んだ量は、ここから残せます」 |
| G3b | スポットライト | オーバーレイ | 画面を `--foreground` 55% で暗くし、H8 の矩形だけを切り抜く。切り抜きの周りに `--background` と `--primary` の二重枠（ぼかし発光は付けない。静止）。H8 は明るいまま押せられる。他の UI（H9・タブ・今日カード）は触れない |
| G3c | 進捗 | テキスト | 「1 / 2」。練習フォームは「2 / 2」 |
| G4 | 対象 | H8 | 「お酒を記録する」を実際に押す。押したら練習フォームへ |
| G5 | 終了 | テキストボタン | 「ガイドを終了」→ `skipped`。吹き出し右下。primary 文字 |

ガイド中に H9「写真から記録」と中央タブへ届いた場合は練習へ逃がし、カメラ・本番フォームを開かない（スポットライトで通常は触れない）。

マスコットは対象（H8）を見てからユーザー側へ視線を移す（M-34）。同じ画面で動くキャラはガイド側の 1 体だけ。ホーム今日カードの待機まばたきは止める。吹き出しは地色 + outset（白い別面を重ねない）。

## `guide-practice` 練習フォーム

見た目は `log-new` の主要欄を再利用する。練習専用の状態を持つ。

| # | 要素 | 種別 | 内容・挙動 |
|---|---|---|---|
| G6 | 帯 | テキスト | 常時「練習中・保存されません」 |
| G7 | 一文 | テキスト | 「量を選んで保存。写真はなくても大丈夫です」 |
| G8 | 種類・量・度数 | 本番部品 | 初期ワイン 125 / 12。量を変えられる |
| G9 | 写真 | 出さない | カメラ・権限要求を起動しない |
| G10 | 練習保存 | Button 主 | 「練習として保存（記録されません）」。API を呼ばず完了へ |
| G11 | 戻る | ヘッダー | 確認なしでホーム案内へ戻れる。実データは変えない |

タブバーは隠す。未保存確認は出さない（保存対象が無い）。

## 受け入れチェック

- [ ] データのない初回だけ招待が出る。既存データがあるユーザーには出ない
- [ ] 「操作を試す」→ 画面が暗くなり H8 だけが枠付きで残る → H8 を押す → 量を変えて練習保存 → 「ガイドを終了」の 2 ステップで終わる
- [ ] タイマーだけで進まない。説明待ちのロックが無い
- [ ] 練習中は保存 API・写真・認識・集計・開栓が走らない
- [ ] 常に「練習中・保存されません」があり、保存操作の意味が練習だと分かる
- [ ] スキップ・戻る・再読込・終了で実データと既存下書きを変えない
- [ ] 設定「使い方を見る」で再実行できる
- [ ] セラー / ノートの初回案内は空状態と統合され、初回ガイドに連続して詰まない
- [ ] セリフは 1〜2 文、一括表示。動くキャラは 1 体
