# 08 初回ガイド

ルートを持たないオーバーレイ。正本の要件は [../features/first-run-guide.md](../features/first-run-guide.md)。

ツアーは 3 本。初回自動は記録だけ。設定「使い方を見る」から扇で選ぶ。

| ツアー | スポットライト | 完了 |
|---|---|---|
| 記録 | ホーム H8 → 量 → 練習保存（1 / 3〜3 / 3） | `guide-done` |
| セラー | 追加 → 種類 → 練習保存 | `guide-cellar-done` |
| ノート | 作成 → 評価 → 練習保存 | `guide-notes-done` |

---

## `guide-invite` 招待

ホームの上に小さなボトムシート。初回ログイン後、データが無いときだけ。

```
┌──────────────────────────────────┐
│ 使い方を少し試してみますか？        │
│ [ 操作を試す ]                     │
│ [ 今はしない ]                     │
└──────────────────────────────────┘
```

| # | 要素 | 種別 | 内容・挙動 |
|---|---|---|---|
| G0 | 見出し | テキスト | 「使い方を少し試してみますか？」 |
| G1 | 操作を試す | Button 主 | `guide-home-record` へ。タイマーでは進まない |
| G2 | 今はしない | Button 副 | 閉じて `skipped`。シート外タップでも同じ |

キャラクターは出さない（ホームの 1 体と重ねない）。

---

## `guide-home-record` 記録ボタン（1 / 3）

ホームの上にスポットライトを重ね、H8 だけを操作対象として示す。ボタン一覧の読み上げはしない。

```
┌──────────────────────────────────┐
│ ░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░ │  画面を暗くする（H8 以外）
│ ░  [ + お酒を記録する ]  ░░░░░░░ │  H8 を切り抜き + primary の枠
│ ░  ┌ 吹き出し ──────────────┐ ░ │
│ ░  │ 飲んだ量は、ここから残せます │ ░ │
│ ░  │ 1 / 3    ガイドを終了   │ ░ │
│ ░  └────────────────────────┘ ░ │
└──────────────────────────────────┘
```

| # | 要素 | 種別 | 内容・挙動 |
|---|---|---|---|
| G3 | 一文 | テキスト | 「飲んだ量は、ここから残せます」 |
| G3b | スポットライト | オーバーレイ | 画面を黒 55% で暗くし（ライト／ダークとも同じ。`--foreground` だとダークで明るくなる）、対象の**見た目の矩形**だけを切り抜く（fieldset の legend・save-bar のボタンなど、border box からのはみ出しを含む。`visualViewport` の offset を引いて `position: fixed` と揃える）。切り抜きの周りに `--background` と `--primary` の二重枠（ぼかし発光は付けない。静止。枠の半径は対象に合わせる）。対象は明るいまま押せられる。他の UI は触れない。練習 overlay より前面（z-index 50）。**対象が見つかるまで暗幕も吹き出しも出さない**（設定から遷移中に設定画面を覆わない）。対象以外を `z-index` で前面に出さない（練習中にホーム H8 や FAB が浮かない）。吹き出しの矢印は対象の中央を指す |
| G3c | 進捗 | テキスト | 「1 / 3」。量は「2 / 3」。保存は「3 / 3」 |
| G4 | 対象 | H8 | 「お酒を記録する」を実際に押す。押したら練習フォームへ |
| G5 | 終了 | テキストボタン | 「ガイドを終了」→ `skipped`。吹き出し右下。primary 文字 |

ガイド中に H9「写真から記録」と中央タブへ届いた場合は練習へ逃がし、カメラ・本番フォームを開かない（スポットライトで通常は触れない）。

マスコットは対象を見てからユーザー側へ視線を移す（M-34）。同じ画面で動くキャラはガイド側の 1 体だけ。ホーム今日カードの待機まばたきは止める。吹き出しは地色 + outset（白い別面を重ねない）。

## `guide-practice-volume` 量（2 / 3）

見た目は `log-new` の主要欄を再利用する。練習専用の状態を持つ。スポットライトは量欄に当てる。

| # | 要素 | 種別 | 内容・挙動 |
|---|---|---|---|
| G6 | 帯 | テキスト | 常時「練習中・保存されません」＋進捗 |
| G7 | 一文 | — | **出さない**。スポットライト（G8b / G10b）が一文を担う。フォーム内リードと重ねない |
| G8 | 種類・量・度数 | 本番部品 | 初期赤ワイン 125 / 12。量を変えられる |
| G8b | スポットライト | 量欄 | 「量を選ぶ。写真はなくても大丈夫です」。量を変えたら保存へ進む |
| G9 | 写真 | 出さない | カメラ・権限要求を起動しない |
| G11 | 戻る | ヘッダー | 確認なしでホーム案内へ戻れる。実データは変えない |

タブバーは隠す。未保存確認は出さない（保存対象が無い）。

## `guide-practice-save` 保存（3 / 3）

同じ練習フォームのまま、スポットライトを保存へ移す。

| # | 要素 | 種別 | 内容・挙動 |
|---|---|---|---|
| G10 | 練習保存 | Button 主 | 「練習として保存（記録されません）」。API を呼ばず完了へ |
| G10b | スポットライト | 保存バー | 「ここを押すと練習として保存されます。記録には残りません」 |

量を飛ばして保存しても完了してよい（練習値は捨てる）。

## `guide-done` 完了

| # | 要素 | 種別 | 内容・挙動 |
|---|---|---|---|
| G12 | 一文 | テキスト | 「記録の基本はこれだけです」 |
| G12b | 補足 | テキスト | 「セラーやノートは、設定の「使い方を見る」から試せます」 |
| G13 | 終了 | Button 主 | 「ガイドを終了」→ `completed`。短く 1 回ウィンク（M-35） |
| G13b | ほかの使い方 | Button 副 | 「ほかの使い方を見る」→ 設定へ行き扇メニューを開く。「使い方を見る」行が見える位置までスクロールし、記録 / セラー / ノートがタブに隠れないようにする |

セラー・ノートの説明をこのシートに詰め込まない。導線だけ置く。

## セラーツアー

設定の扇「セラー」または完了の「ほかの使い方を見る」から。招待は出さない。

| ステップ | 進捗 | 対象 | 一文 |
|---|---|---|---|
| `guide-cellar-add` | 1 / 3 | 空状態「ボトルを追加」または右下 FAB | 持っているボトルを、ここに並べて管理します |
| `guide-cellar-type` | 2 / 3 | 種類チップ | 種類を選ぶ。写真があれば色や泡から推測します |
| `guide-cellar-save` | 3 / 3 | 練習保存 | 練習として並べる。棚には残りません |
| `guide-cellar-done` | — | 完了シート | 「セラーの基本はこれだけです」＋「ほかの使い方を見る」 |

練習フォームは品名（固定「練習用」）と種類と保存だけ。写真・本番 API なし。戻るはセラー一覧案内へ。

## セラー / ノート初回（ツアー外）

空状態の補助文を 1 行だけ足す。記録ツアーには連続して詰まない。

| 画面 | 既存 | 初回だけ足す一文 |
|---|---|---|
| セラー空 | 「ボトルはまだありません。撮って 1 本目を並べましょう」 | 「持っているボトルを、ここに並べて管理します」 |
| ノート空 | 「テイスティングノートはまだありません」 | 補助を「味や感想は、ノートに残します」に置き換える（「気になるお酒の味わいを記録してみましょう」と重複させない） |

見た時点で `cellarHintSeen` / `notesHintSeen` を立て、次回は既存の空状態だけ。**ツアー中は補助文を出さない**（スポットライトの一文と重複させない）。空状態の主ボタンがあるときはそれを切り抜き、FAB は右下のまま動かさない。

## `settings` からの再実行

[06-settings.md](06-settings.md) S11。「使い方を見る」で扇メニュー（M-37）を開く。機能名 3 つ（記録 / セラー / ノート）が行の上に扇状に並ぶ。タップでそのツアーの 1 歩目へ（招待は省略）。完了・スキップは上書きする。backdrop タップで閉じる。reduced motion では扇の回転をやめ、縦に積む。

```
┌──────────────────────────────────┐
│            [記録]                 │
│     [セラー]     [ノート]          │
│ ┌ 使い方を見る ──────────────┐  │
└──────────────────────────────────┘
```

## 受け入れチェック

- [ ] データのない初回だけ招待が出る。既存データがあるユーザーには出ない
- [ ] 「操作を試す」→ 画面が暗くなり H8 だけが枠付きで残る → H8 を押す → 量欄がハイライト → 量を変える → 保存がハイライト → 練習保存 → 「ガイドを終了」または「ほかの使い方を見る」
- [ ] 練習フォームでもスポットライトが消えず、次の操作が一文で分かる
- [ ] タイマーだけで進まない。説明待ちのロックが無い
- [ ] 練習中は保存 API・写真・認識・集計・開栓が走らない
- [ ] 常に「練習中・保存されません」があり、保存操作の意味が練習だと分かる
- [ ] スキップ・戻る・再読込・終了で実データと既存下書きを変えない
- [ ] 設定「使い方を見る」で扇が開き、記録 / セラー / ノートを選べる。「ほかの使い方を見る」から来たときも選択肢がタブに隠れない
- [ ] 練習の量・種類・評価・保存のスポットライトが対象の見た目に揃う（ラベルを横切らない、保存ボタンの端が暗幕に欠けない）
- [ ] セラー / ノートのツアーもスポットライト 3 歩で保存まで案内する
- [ ] セラー / ノートの初回空状態案内はツアーに連続して詰まない
- [ ] セリフは 1〜2 文、一括表示。動くキャラは 1 体
- [ ] 設定「使い方を見る」からセラー／ノートを選んだとき、設定画面を暗幕で覆わない。対象ページのボタンまたは右下 FAB だけを枠で示す
- [ ] 練習中にホームの「お酒を記録する」や左端の＋が前面に出ない。吹き出しの矢印は対象を指す
