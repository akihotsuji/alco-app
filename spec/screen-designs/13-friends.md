# 13 友達・近況

下部タブ「友達」（旧ノート位置）。独立した投稿作成ボタンは置かない。共有は登録・開栓・詳細から始める。

機能仕様: [features/friends-social.md](../features/friends-social.md)

```
┌──────────────────────────────────┐
│ 友達の近況              🔔  👥   │
├──────────────────────────────────┤
│ ┌[72×88] Aさん · たった今      ┐ │
│ │         飲んだ一杯            │ │
│ │         酒名（最大2行）       │ │
│ │         ひとこと / ★4.2       │ │
│ │         😊 リアクション  2    │ │
│ └──────────────────────────────┘ │
│ ホーム セラー (記録) 友達* 設定   │
└──────────────────────────────────┘
```

## 共通

ニューモーフィズム・16px 本文・`--tap-min`。外部 SNS の見た目は複製しない。絵文字はリアクションマスタの表示と、一覧の「リアクション」操作ラベルだけ（lucide 禁止の例外）。固定バーはタブ・キーボード・safe-area と重ねない。

## `friends-feed` `/friends`

| # | 要素 | 種別 | 内容 |
|---|---|---|---|
| F1 | 見出し | ヘッダー | 「友達の近況」 |
| F2 | 通知 | 右アイコン | `/friends/notifications`。未読バッジ |
| F3 | 友達一覧 | 右アイコン | `/friends/list` |
| F4 | カード | 横型 1 列 | 左にサムネ（72×88 CSS px 目安、`object-fit: contain`）。右に 24px アイコン・名前（1 行省略）・相対時刻、種別、酒名（最大 2 行）、任意の評価/ひとこと（1 行）、リアクション操作。高さの目安は 130〜140 CSS px。文字拡大では自然に伸びる。`overflow: hidden` で操作部を切らない |
| F5 | 種別 | ラベル | 「飲んだ一杯」「セラーに仲間入り」「開けた一本」「セラーに N 本追加」 |
| F6 | 空 | 文 | 友達 0: 「友達を追加すると、共有されたお酒の記録がここに表示されます」。友達あり投稿なし: 「友達になった後に共有された記録が表示されます」。空からも「友達を招待」「招待リンクを貼る」へ進める |
| F7 | 続き | ボタン | 20 件。スクロール位置を保持 |
| F8 | 代表写真 | 画像 | 先頭の表示可能な画像。別アイテムにあればそれを使う。なし・失敗は同じ枠のボトルシルエット。`items.length > 1` は「＋N本」（N は残りのアイテム数）。一覧はサムネ API。詳細の `.social-card-photo` は変えない |
| F9 | リアクション | ボタン | 一覧は 1 操作。未反応は「😊 リアクション」。自分の反応ありはその絵文字と名称。他者の反応は代表絵文字最大 2 と合計人数。0 件のチップを並べない。`canReact: false` は集計のみ。押すとシート |

状態: 読込 / 空 / 失敗+再試行 / 権限失効（再取得で消える）。サンプル投稿は出さない。

写真・本文は `/friends/posts/:id`。リアクションボタンは詳細リンクの外。リンク内にボタンを入れない。

基準ビューポート 390×844 CSS px・標準文字で、ヘッダーと下部ナビ（中央ボタンの張り出しを含む）を除いた初期表示に、最大構成のカード 4 枚全体が入る。

## `friends-list` `/friends/list`

承認済み、受信申請（承認/辞退）、自分の申請中（取消）、招待ボタン、**招待リンクを貼る**（`/friends/join` の貼り付け）。解除は確認。ブロックは設定から。

行は横並び: アバター + **名前（横書き・1 行。長いときは省略）** + 操作。操作ボタンは行幅いっぱいに伸ばさない（名前が縦に折れるのを防ぐ）。ブロック一覧も同じ。

承認成功は「○○さんと友達になりました」を出してホーム `/` へ（`replace`）。処理中は対象行の承認・辞退を無効化する。

## `friends-invite` `/friends/invite`

同じ招待 URL のテキストと QR。コピー・端末共有（文言「酒のしおりで友達になる」）。期限 7 日。再発行で旧リンク無効。コピー成功は `writeText` の成功後。失敗時は選択して手動コピーできる欄を出す。プロフィール未設定でも発行できる。

## `friends-join` `/friends/join`

トークンは `#t=`。最初に URL から読み、同一コンテキストの一時保存に残してハッシュを消す。新しい URL が古い保存より優先。ハッシュ消失後も受信した招待 URL を再構築してコピーできる。

| 状態 | 表示・操作 |
|---|---|
| 読み込み中 | ローディング。トークン取り込み前に期限切れと出さない |
| 未ログイン | 「ログインして続ける」（ログイン後に同じ招待へ復帰）と「招待リンクをコピー」。コピー後に「ホーム画面から酒のしおりを開き、友達 → 友達を追加で貼り付けてください」 |
| トークンなし（ログイン済） | 招待リンクの貼り付け欄。検証 → プレビュー → 「友達申請を送る」。自動申請しない。クリップボード自動読取はしない。補助の貼り付けが失敗しても手入力は残す |
| 正常な招待 | 相手のアイコンと名前、申請ボタン |
| 申請済み | 「申請済みです。相手の承認を待っています」＋ホームへ |
| すでに友達 | 「すでに友達です」＋ホームへ |
| 相手から申請あり | 「届いた申請を確認」→ 友達一覧。承認成功後はホームへ |
| 自分の招待 | 自分への申請不可と分かる表示 |
| 無効・期限切れ・失効 | 再取得が必要な旨と、貼り付け / ホーム |
| ネットワーク・API 失敗 | 再試行。正常な招待を期限切れにしない |

申請成功は「友達申請を送りました」を出してホーム `/` へ（`replace`）。受信トークンの一時保存を消す。無効確定でも古い状態を再利用しない。通信失敗では再試行のため残す。

インストール済み PWA の自動起動は端末依存。同じ URL を開き直すだけの「アプリで開く」や、インストール済みと断言する UA 判定は置かない。

## `friends-profile` `/friends/profile/:id`

閲覧可能な相手の名前/アイコンと、その相手の閲覧可能な共有だけ。非友達は 404 相当。名前はアカウント表示名。

## `friends-post` `/friends/posts/:id`

共有詳細。写真は従来どおり大きく（`.social-card-photo`）。詳細テイスティングは「詳しく見る」。リアクション。本人は元データ編集へ。共有取消。

## `friends-notifications` `/friends/notifications`

未読/既読、すべて既読。申請の承認/辞退。失効した操作ボタンは出さない。承認成功は「○○さんと友達になりました」を出してホーム `/` へ。

## `settings-profile` `/settings/profile`

**アイコン（任意）**。ワイン君色（プリセット+ピッカー）または画像（円形トリミング）。画像削除でワイン君へ復帰。友達用の別名入力は置かない。名前の編集は設定の表示名。画像の保存・削除で名前は変えない。

## 設定内

表示名は「ニックネーム（友達にも表示されます）」。共有の初期選択。ブロック一覧と解除。テイスティングノート一覧への行（`/notes`）。アイコン設定は「アイコン（任意）」→ `/settings/profile`。

## 登録・詳細の共有欄

見出し「酒のしおりの友達に共有」。説明「このアプリで友達になった人だけが見られます」。スイッチ。ON 時プレビュー。OFF「保存」/ ON「保存して友達に共有」。初回に遡及公開しない旨。マイドリンクワンタップは保存後シート。友達 0 人では共有不可の説明だけ。プロフィール行の有無では止めない。

編集中の共有済み: 「変更は友達への共有内容にも反映されます」。削除確認: 「友達への共有とリアクションも削除されます」。バッチ一部削除の例外をボトル削除確認に出す。

## 受け入れチェック

- [ ] 下部タブがホーム / セラー / 飲酒を記録 / 友達 / 設定。ノートタブは無い
- [ ] `/notes` は設定またはボトル詳細から開ける
- [ ] フィード空文が友達 0 / 投稿 0 で分かれる。サンプル投稿が無い。空から招待と貼り付けへ進める
- [ ] 基準 390×844 で最大構成の 4 投稿全体が見え、カードと下部ナビ（中央ボタン含む）が重ならない
- [ ] 一覧は横型。写真なし・失敗・複数本・長い英字名で崩れない。詳細写真は大きい
- [ ] 一覧のリアクションが 1 操作のシート。変更・解除・失敗時の復旧ができる。閉じた後も縦スクロールできる
- [ ] 招待リンクと QR が同じ URL。申請だけでは友達にならない
- [ ] 公開名はアカウント表示名。空は「ユーザー」。メールや OAuth 本名を自動で埋めない
- [ ] 友達用の別名入力が無い。アイコンは任意。ワイン君は液体色だけ変わり、ホーム全体の色は変わらない
- [ ] 共有スイッチの既定が設定に従い、操作ごとの変更は設定を変えない
- [ ] 友達 0 でも個人保存できる。プロフィール行なしでも招待・申請・承認・共有できる
- [ ] フィード/詳細/画像が受信対象かつ有効世代の友達だけに見える
- [ ] 共有後の編集で内容は更新され、時刻・受信者・反応は維持される
- [ ] 解除・ブロック・再承認で旧投稿/画像が復活しない
- [ ] 共有取消で投稿は消え、元記録は残る
- [ ] 開栓→記録の共有が 1 件。まとめ登録の成功分が 1 件
- [ ] リアクションが 1 人 1 種。マスタ追加がデプロイなしで出る
- [ ] 通知が申請・承認・反応だけ。失効後に再承認できない
- [ ] 独立した投稿作成ボタンが無い
- [ ] 友達一覧・申請行・ブロック一覧の名前は横書き（1 行。長いときは省略）。操作は名前の右
- [ ] ブラウザで受信した招待をコピーし、PWA で貼り付けて申請できる。申請・承認の成功はホームへトースト付き
