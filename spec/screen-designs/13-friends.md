# 13 友達・近況

下部タブ「友達」（旧ノート位置）。独立した投稿作成ボタンは置かない。共有は登録・開栓・詳細から始める。

機能仕様: [features/friends-social.md](../features/friends-social.md)

```
┌──────────────────────────────────┐
│ 友達の近況              🔔  👥   │
├──────────────────────────────────┤
│ ┌ Aさん · たった今 · 飲んだ一杯 ┐ │
│ │ [写真] 酒名  ★4.2  ひとこと   │ │
│ │ 😊 2  😍 1                    │ │
│ └──────────────────────────────┘ │
│ ホーム セラー (記録) 友達* 設定   │
└──────────────────────────────────┘
```

## 共通

ニューモーフィズム・16px 本文・`--tap-min`。外部 SNS の見た目は複製しない。絵文字はリアクションマスタの表示だけ（lucide 禁止の例外）。固定バーはタブ・キーボード・safe-area と重ねない。

## `friends-feed` `/friends`

| # | 要素 | 種別 | 内容 |
|---|---|---|---|
| F1 | 見出し | ヘッダー | 「友達の近況」 |
| F2 | 通知 | 右アイコン | `/friends/notifications`。未読バッジ |
| F3 | 友達一覧 | 右アイコン | `/friends/list` |
| F4 | カード | リスト | 現在の名前/アイコン、共有時刻、種別ラベル、写真、酒名、評価/ひとこと、リアクション。編集済みは実変更時のみ |
| F5 | 種別 | ラベル | 「飲んだ一杯」「セラーに仲間入り」「開けた一本」「セラーに N 本追加」 |
| F6 | 空 | 文 | 友達 0: 「友達を追加すると、共有されたお酒の記録がここに表示されます」。友達あり投稿なし: 「友達になった後に共有された記録が表示されます」 |
| F7 | 続き | ボタン | 20 件。スクロール位置を保持 |

状態: 読込 / 空 / 失敗+再試行 / 権限失効（再取得で消える）。サンプル投稿は出さない。

## `friends-list` `/friends/list`

承認済み、受信申請（承認/辞退）、自分の申請中（取消）、招待ボタン。解除は確認。ブロックは設定から。

## `friends-invite` `/friends/invite`

同じ招待 URL のテキストと QR。コピー・端末共有（文言「酒のしおりで友達になる」）。期限 7 日。再発行で旧リンク無効。

## `friends-join` `/friends/join`

未ログインは通常ログイン後に復帰。招待者のニックネーム/アイコンのみ。申請。無効リンクは一般案内。投稿は見えない。

## `friends-profile` `/friends/profile/:id`

閲覧可能な相手の名前/アイコンと、その相手の閲覧可能な共有だけ。非友達は 404 相当。

## `friends-post` `/friends/posts/:id`

共有詳細。写真拡大。詳細テイスティングは「詳しく見る」。リアクション。本人は元データ編集へ。共有取消。

## `friends-notifications` `/friends/notifications`

未読/既読、すべて既読。申請の承認/辞退。失効した操作ボタンは出さない。

## `settings-profile` `/settings/profile`

友達に表示する名前（1〜30、本名を埋めない）。ワイン君色（プリセット+ピッカー）または画像（円形トリミング）。画像削除で色へ復帰。

## 設定内

共有の初期選択。ブロック一覧と解除。テイスティングノート一覧への行（`/notes`）。

## 登録・詳細の共有欄

見出し「酒のしおりの友達に共有」。説明「このアプリで友達になった人だけが見られます」。スイッチ。ON 時プレビュー。OFF「保存」/ ON「保存して友達に共有」。初回に遡及公開しない旨。マイドリンクワンタップは保存後シート。

編集中の共有済み: 「変更は友達への共有内容にも反映されます」。削除確認: 「友達への共有とリアクションも削除されます」。バッチ一部削除の例外をボトル削除確認に出す。

## 受け入れチェック

- [ ] 下部タブがホーム / セラー / 飲酒を記録 / 友達 / 設定。ノートタブは無い
- [ ] `/notes` は設定またはボトル詳細から開ける
- [ ] フィード空文が友達 0 / 投稿 0 で分かれる。サンプル投稿が無い
- [ ] 招待リンクと QR が同じ URL。申請だけでは友達にならない
- [ ] 公開名に OAuth 本名・メールが自動で入らない
- [ ] ワイン君は液体色だけ変わり、ホーム全体の色は変わらない
- [ ] 共有スイッチの既定が設定に従い、操作ごとの変更は設定を変えない
- [ ] 友達 0・プロフィール未設定でも個人保存できる
- [ ] フィード/詳細/画像が受信対象かつ有効世代の友達だけに見える
- [ ] 共有後の編集で内容は更新され、時刻・受信者・反応は維持される
- [ ] 解除・ブロック・再承認で旧投稿/画像が復活しない
- [ ] 共有取消で投稿は消え、元記録は残る
- [ ] 開栓→記録の共有が 1 件。まとめ登録の成功分が 1 件
- [ ] リアクションが 1 人 1 種。マスタ追加がデプロイなしで出る
- [ ] 通知が申請・承認・反応だけ。失効後に再承認できない
- [ ] 独立した投稿作成ボタンが無い
