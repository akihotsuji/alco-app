## `legal-terms` 利用規約

| ルート | 親タブ | タブバー | ヘッダー | 主アクション |
|---|---|---|---|---|
| `/terms` | なし | なし | 「利用規約」+ 戻る | なし |

ログイン前・ログイン後のどちらでも表示する。認証ガードに入れない。

```
┌──────────────────────────────────┐
│ ←          利用規約              │
├──────────────────────────────────┤
│ 草案の短い注記（13px muted）       │
│ 版と施行日                         │
│                                  │

│ プライバシーポリシーを見る         │  文字リンク → /privacy（from を引き継ぐ）
└──────────────────────────────────┘
```

### 要素表

| # | 要素 | 種別 | 内容・挙動 | データ / API |
|---|---|---|---|---|
| T1 | 戻る | IconButton | 履歴があれば戻る。無ければ `from`（`signup` / `login` / `settings`）。不正・無しは `/signup` | クライアント |
| T2 | 見出し | テキスト | 「利用規約」 | — |
| T3 | 注記 | テキスト | 「一般公開準備の草案です。法的な確定は運営者の承認後です。」 | `LEGAL_DRAFT_NOTICE` |
| T4 | 版 | テキスト | 版と施行日 | `LEGAL_VERSION` / `LEGAL_EFFECTIVE_ON` |
| T5 | 本文 | 見出し + 段落 + 箇条書き | `src/shared/legal-documents.ts` の terms。**テキストとして描画**。HTML 埋め込み禁止 | 共有定数 |
| T6 | 関連 | リンク | 「プライバシーポリシー」→ `/privacy`（`from` 維持） | — |

## `legal-privacy` プライバシーポリシー

| # | 要素 | 内容 |

## 操作と遷移

| 操作 | 結果 |
|---|---|
| サインアップの「利用規約」 | `/terms?from=signup` |
| サインアップの「プライバシーポリシー」 | `/privacy?from=signup` |
| 設定の「利用規約」 | `/terms?from=settings` |
| 設定の「プライバシーポリシー」 | `/privacy?from=settings` |
| 戻る（履歴あり） | 直前の画面 |
| 戻る（履歴なし） | `from` のフォールバック |
