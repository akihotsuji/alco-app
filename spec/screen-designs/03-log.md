## `log-day` 日別記録（中央タブの着地）

| ルート | 親タブ | タブバー | ヘッダー | 主アクション |
|---|---|---|---|---|
| `/logs`（今日）、`/logs/:date` | log | 表示 | 日付「9月5日」（今日は「今日」） | 記録する |

目的: 今日の一覧と合計。**記録の入口を最上部にまとめる**（中央タブから 2 タップで保存）。

```
┌──────────────────────────────────┐
│ ‹        今日        ›            │  日送り（未来へは進めない）
├──────────────────────────────────┤
│ 2 杯 ・ 28 g                      │  13px/600 muted。0 のとき「休肝」ピル
│ [      記録する      ] [📷]       │  主 + カメラ円 52px
│ [赤ラベル 125ml] [ハイボール] 管理│  マイドリンク 1 タップ（最大 4）
│                                  │
│ ┌ 行 ─────────────────────────┐  │
│ │[写真] ワイン 125ml       12g ›│  │  サムネ 48px（無ければ種類アイコン）
│ │       13:05 ・ 12% ・ 🍾サンプル赤│  │  ボトル紐付きは名前を表示
│ └──────────────────────────────┘  │
│ ┌ 行 ─────────────────────────┐  │
│ │[  ] ハイボール 120ml    14g ›│  │
│ │       21:10 ・ 15%            │  │
│ └──────────────────────────────┘  │
├──────────────────────────────────┤
│ ホーム  セラー  (記録*) ノート  設定│
└──────────────────────────────────┘
```

### 要素表

| # | 要素 | 種別 | 内容・挙動 | データ / API |
|---|---|---|---|---|
| D1 | 日送り | ヘッダー左右（円ボタン） | 前日 / 翌日。翌日が未来なら右を無効 | `/logs/:date` |
| D2 | 合計 | テキスト | 「N 杯 ・ g」。0 件は「休肝」ピル | `GET /api/drink-logs?date=` の `totalCount` / `totalAlcoholG` |
| D3 | 記録する | Button 主 | `/logs/new?date=<表示日>`（今日なら `date` 省略） | — |
| D4 | カメラ | Button 副（円 52px） | `/logs/new?date=&camera=1` | — |
| D5 | マイドリンク | Chip（最大 4）+「管理」 | ホームと同じ 1 タップ。**表示日**の `drunkAt` は「その日の現在時刻」（過去日なら 20:00 JST 固定） | `POST /api/my-drinks/:id/log` |
| D6 | 記録行 | 行（64px 以上） | 1 行目: 「種類（またはマイドリンク名 / ボトル名） 量ml」 右に g。2 行目: 「時刻 ・ 度数 ・ ボトル名（あれば）」。左サムネ 48px（写真があれば。無ければ種類アイコン inset） | `items[]`（`thumbPhotoId`, `bottleId`, `drinkName`） |
| D7 | 行タップ | — | `log-edit` | — |
| D8 | ハイライト | — | `?highlight=<logId>` の行を 2 秒だけ inset + primary 枠（消費・保存直後） | — |

### 状態

| 状態 | 表示 |
|---|---|
| ローディング | 合計枠 + 行プレースホルダ 3 |
| 空 | 合計「休肝」。行の代わりに「この日の記録はまだありません」（キャラなし。上のボタン群が主アクション） |
| エラー | 「読み込めませんでした」+ 再試行 |
| 保存直後（`log-new` から戻る） | 該当行を D8 でハイライト。トーストは `log-new` 側で出す |
| 消費直後（セラーから） | D8 + トースト「貯蔵庫へ移しました  取り消す」（[04-cellar.md](04-cellar.md)） |

`:date` は `^\d{4}-\d{2}-\d{2}$` 以外は `not-found`。未来日は表示できるが記録ボタンは無効（+15 分ルール）。

## `log-new` 記録入力

| ルート | 親タブ | タブバー | ヘッダー | 主アクション |
|---|---|---|---|---|
| `/logs/new?date=&camera=1&bottleId=` | log | **隠す** | ← 「記録する」 | 保存する |

目的: **種類 → 保存の 2 タップ**を守りつつ、写真を撮って一杯を残せる。

```
┌──────────────────────────────────┐
│ ←  記録する                       │
├──────────────────────────────────┤
│ ┌ 写真タイル（120px） ─────────┐  │  撮影前: 📷 写真を撮る ＋ [Mascot surprised 48]
│ └──────────────────────────────┘  │  撮影後: [96×120 サムネ] 編集 / 削除
│ 種類                              │
│ [ワイン*][ビール][ウイスキー][日本酒]│  横スクロール。初期はワイン
│ [焼酎][カクテル][その他]           │
│ 量                                │
│  125 ml                           │  40px
│ [125*][150][375][750][1500][手入力]│  グラス量 + ボトル量 + 手入力
│ 度数                              │
│  12 %      [ − ] [ ＋ ]           │  0.1 刻み。長押しで連続
│ ＝ 12.0 g                          │  ライブ計算（13px muted）
│ 日時   今日 13:05              ›  │  行。タップで日時ピッカー
│ ボトル  選ぶ                   ›  │  任意。セラー（貯蔵庫含む）から
│ メモ   任意                    ▼  │  折りたたみ。500 文字
├──────────────────────────────────┤
│ [          保存する          ]   │  固定バー
└──────────────────────────────────┘
```

| # | 要素 | 種別 | 内容・挙動 | データ / API |
|---|---|---|---|---|
| N1 | 写真タイル | 写真タイル | タップで `photo-edit`（比率 4:5、プリセット `table`、キャラ合成トグルあり）。`?camera=1` ならマウント直後に開く。1 枚のみ | `POST /api/photos`（未紐付け）→ `photoId` を保持 |

| N4 | 量 | スコア 40px + Chip | 種類の量チップ + ボトル量 375/750/1500 + 「手入力」（数値キーボード、1〜5000 整数） | — |

| N6 | ライブ g | テキスト 13px | `calculateAlcoholGrams` → 表示丸め。量・度数が空なら「—」 | `src/shared` |
| N7 | 日時 | 行 | 既定「今日 HH:MM」（`?date=` 指定時は「9月4日 20:00」）。ネイティブ `datetime-local` | `drunkAt` |
| N8 | ボトル | 行 | 「選ぶ ›」→ ボトルピッカー（下から出るダイアログ。検索 + 棚と同じ 2:3 サムネの行。貯蔵庫も含む）。選ぶと種類をボトルの種類で上書き、名前を表示。`?bottleId=` で事前選択 | `GET /api/bottles?q=&view=all` |

### 状態

| 状態 | 表示 |
|---|---|
| 初期 | ワイン 125 / 12、日時いま、写真なし。**すぐ保存できる** |
| `camera=1` | `photo-edit` が先に開く。×で閉じても本画面は残る |
| 写真アップロード中 | サムネ上に進捗リング。保存ボタンは「写真を保存中」で無効 |
| 写真アップロード失敗 | サムネに「!」と「再試行」。保存は写真なしでは進めない（削除すれば進める） |
| 保存中 | ボタン「保存中」無効 |
| 保存失敗 | 上部インライン汎用文。入力保持 |
| 成功 | 対象日の `log-day?highlight=<id>` へ `replace`。トースト「記録しました」（`cheer`） |
| 戻る（未保存） | 入力ありなら確認ダイアログ「入力を破棄しますか」。写真は `DELETE /api/photos/:id` |

### 操作と遷移（タップ数）

| 経路 | タップ |
|---|---|
| 種類そのまま保存 | **1**（保存） |
| 種類を変えて保存 | 2 |
| 撮る → 使う → 保存 | 3（撮影の OS 操作は含めない） |
| 「その他」 | 種類 + 量 + 度数 + 保存 |

### バリデーション

| 項目 | 規則 | エラー文 |
|---|---|---|
| 量 | 整数 1〜5000 | 「1以上5000以下で入力してください」 |
| 度数 | 0〜100、小数第 1 位 | 「0以上100以下で入力してください」 |
| 日時 | 現在 +15 分まで | 「未来の日時は指定できません」 |
| メモ | 500 文字 | 「500文字以内で入力してください」 |
| ボトル | 自分のもの（サーバー 404） | 「ボトルが見つかりません」 |

### キャラクター

写真タイル（撮影前）の右下に `surprised` 48px。撮影後・その他の場所には出さない。合成トグルは `photo-edit` 内。

## `log-edit` 記録編集

`/logs/entries/:logId/edit`。`log-new` と同じレイアウト。差分:

- ヘッダー「記録を編集」。初期値は既存の値（写真があればサムネ）
- 種類を変えても量・度数は **上書きしない**（編集中の値を守る）。変えたい場合はチップで
- 保存 → `PATCH /api/drink-logs/:id`（変えたフィールドのみ）→ 対象日の `log-day`
- 保存バーの下にテキストボタン「この記録を削除」→ 確認ダイアログ（danger）→ `DELETE` → `log-day`。トースト「削除しました」（キャラなし）
- 写真の付け替え: 削除して撮り直し（`DELETE /api/photos/:id` → 新規アップロード → `PATCH` の `photoIds`）

## `mydrink-new` / `mydrink-edit`

`/logs/my-drinks/new`、`/logs/my-drinks/:myDrinkId/edit`。タブ隠す。

| # | 要素 | 内容 |
|---|---|---|
| M1 | 名前 | Input 1〜40 文字。必須 |
| M2 | 種類 | Chip ×7（量・度数を上書き。`log-new` と同じ） |
| M3 | 量 / 度数 | `log-new` と同じ部品。「その他」も値必須 |
| M4 | 保存 | `POST` / `PATCH /api/my-drinks` → 一覧 |
| M5 | 削除（edit のみ） | 確認ダイアログ「過去の記録は残ります」→ `DELETE` |

写真・キャラは置かない（プリセットは数値の画面）。
