## `log-day` 日別記録（ホーム配下。一覧・合計・編集・削除）

| ルート | 親タブ | タブバー | ヘッダー | 主アクション |
|---|---|---|---|---|
| `/logs`（今日）、`/logs/:date` | home | 表示 | 日付「9月5日」（今日は「今日」） | なし（閲覧・編集の画面） |

目的: その日の一覧と合計を見て、行から編集・削除する。**中央タブの着地ではない**（2026-09-06 (c)）。記録の入口（記録する / カメラ / マイドリンク）は [02-home.md](02-home.md) に集約し、この画面には置かない。

入口（4 つ。[../screens.md](../screens.md) 入場経路）:

1. ホームの今日カード（H2）→ 今日の `/logs`
2. ホームの週マス（H6）→ その日の `/logs/:date`（未来は無効。X6）
3. `log-new` / `log-edit` の保存後 → 対象日の `/logs?highlight=<id>` または `/logs/:date?highlight=<id>`
4. 週サマリーの日別行（W4）→ その日の `/logs/:date`

戻り: 履歴戻り（無ければ `/`）。ヘッダー左右は日送りに使うため戻るボタンは置かない。ホームタブが現在地なので、タブでもホームへ戻れる。

```
┌──────────────────────────────────┐
│ ‹        今日        ›            │  日送り（未来へは進めない）
├──────────────────────────────────┤
│ 2 杯 ・ 28 g                      │  13px/600 muted。0 のとき「休肝」ピル
│ [地図] その日いた場所              │  店名または座標があるとき。1 件なら見出しがリンク
│                                  │
│ ┌ 行 ─────────────────────────┐  │
│ │[写真] ワイン 125ml       12g ›│  │  サムネ 48px（無ければ種類アイコン）
│ │       13:05 ・ 12% ・ 🍾サンプル赤│  │  ボトル紐付きは名前を表示
│ └──────────────────────────────┘  │
│ ┌ 行 ─────────────────────────┐  │
│ │[  ] ハイボール 120ml    14g ›│  │
│ │       21:10 ・ 15%            │  │
│ └──────────────────────────────┘  │
├──────────────────────────────────┤
│ ホーム* セラー  (記録)  ノート  設定│  現在地はホーム。中央タブは沈まない
└──────────────────────────────────┘
```

## `log-edit` 記録編集

`/logs/entries/:logId/edit`。`log-new` と同じレイアウト。差分:

- ヘッダー「記録を編集」。初期値は既存の値（写真があればサムネ）
- 種類を変えても量・度数は **上書きしない**（編集中の値を守る）。変えたい場合はチップで
- 保存 → `PATCH /api/drink-logs/:id`（変えたフィールドのみ）→ 対象日の `log-day`
- 保存バーの下にテキストボタン「この記録を削除」→ 確認ダイアログ（danger）→ `DELETE` → `log-day`。トースト「削除しました」（キャラなし）
- 写真の付け替え: 撮り直す / 選ぶ（中間編集なし）または削除して撮り直し。新規写真があれば空欄だけ AI 補完する。サムネタップで拡大
- 場所の現在地は **自動取得しない**（店名・既存座標の維持は可。S12 が ON でも編集では取らない）
- 保存後にノート導線は出さない（`log-new` のみ）

## 受け入れチェック（3-02 / 3-03 / 3-05）

- [ ] `log-day` は一覧・合計・行の編集・削除だけ（「記録する」「カメラ」「マイドリンク」が無い）。入口はホームの今日カード / 週マス / 保存後 / 週サマリーの行で、親タブはホーム（中央タブは沈まない）
- [ ] 中央タブ「記録」→ 空の `log-new`（カメラは開かない）。写真はフォーム内の「写真を撮る / 選ぶ」だけ。ホームに記録・撮影ボタンは無い
- [ ] 写真ゾーンが種類より上（フォーム先頭）。小さな「写真を撮る / 選ぶ」のまま
- [ ] `log-new` 初期赤ワイン 125 / 12 で **保存 1 タップ**。種類変更で量・度数上書き。写真ありなら種類・量を補完して先に選んだ状態にする（触った欄とボトル由来は上書きしない。国・品種は根拠があるときだけ）
- [ ] 写真は「写真を撮る」「写真を選ぶ」の小さなボタン。明示タップ以外（マウント・`?camera=1`・戻り・再表示）では起動しない。撮影後に色補正・キャラ選択・「この写真を使う」を挟まない。処理中・失敗は欄内。撮影キャンセルで入力は残る
- [ ] 詳細入力中・編集・日別サムネの写真タップで全体を拡大できる。閉じる / Escape / 戻るで入力を失わず閉じ、スクロールが戻る。撮り直しと再試行は拡大と別操作
- [ ] 量は数値+ml の直接入力。種類のよく使う量を近くに、残りは「その他」。ボトル量 375 / 750 / 1500 は残す。125ml を全種類に一律しない
- [ ] 度数は − / 数値 / % / ＋ を近接。直接入力可。純アルコール量は「純アルコール量 ○○ g」
- [ ] 初期表示で未操作欄に赤いエラーを並べない。保存無効時は短い説明。保存中は二重送信しない。失敗時は入力を保持
- [ ] ライブ g 表示が保存値の丸めと一致
- [ ] ボトル紐付けは種類の次。「セラーのボトルと関連付ける（任意）」。後選択・解除で手入力を消さない。ボトル詳細・開栓後だけ上部に「対象：○○」。API は自分のボトル（貯蔵庫含む）と `?bottleId=` を受け付ける
- [ ] 読み取り中は写真欄の下にスピナー + 「写真を読み取っています…」、かつ AI が入れる可能性のある欄と種類行に「読み取り中」ピルが出る。結果で「写真から N 項目を入れました」と入った欄の AI 印に置き換わる。0 件・失敗は黙らず 1 行で知らせる（手入力は続けられる）
- [ ] 生産国はコンボボックス。空なら「よく使う国」チップで 1 タップ。打ち始めると直下に候補（≦8）が出てタップで確定。ひらがな・英語でも当たる。× で消せる。`datalist` は無い

- [ ] 自動入力できない国の候補（`originCandidate`）は生産国が空欄のとき「写真からの候補」チップで出て、タップで入る。自動では入らない
