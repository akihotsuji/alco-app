## `home` ホーム

| ルート | 親タブ | タブバー | ヘッダー | 主アクション |
|---|---|---|---|---|
| `/` | home | 表示 | 「ホーム」 | 記録する（`log-new`） |

目的: 今日の状態を 1 秒で把握し、最短で記録に入る。**記録の入口（記録する / カメラ / マイドリンク）はこの画面に集約する**（日別 `log-day` には置かない。2026-09-06）。日別・週 / 月サマリーへの入口もここ。

```
┌──────────────────────────────────┐
│              ホーム               │
├──────────────────────────────────┤
│ 9月5日 土曜                        │  日付 13px/600 muted（JST）
│ ┌ 今日 ──────────────── 今週 › ┐  │  カードタップ → 今日の /logs。右上「今週 ›」→ 週サマリー
│ │  2              28          │  │  スコア 40px。杯 / g
│ │  杯             g 純アルコール │  │
│ │  月 火 水 木 金 土 日          │  │
│ │  ■  ■  □  ■  □  ▣  □       │  │  ■ 記録あり ▣ 今日 □ なし。マス → その日の /logs/:date
│ └───────────────────[Mascot]──┘  │  キャラ 72px が右下から覗く
│                                  │
│ [      記録する      ] [📷]       │  主ボタン（写真なし → log-new）+ カメラ円 52px（撮影から。中央タブと同じ）
│                                  │
│ マイドリンク                 管理  │
│ [赤ラベル 125ml] [ハイボール]     │  チップ 1 タップ記録
│                                  │
├──────────────────────────────────┤
│ ホーム* セラー  (記録)  ノート  設定│
└──────────────────────────────────┘
```

### 状態

| 状態 | 表示 |
|---|---|
| ローディング | カード枠 + ボタン外形のスケルトン。チップは 2 個の枠 |
| 記録 0 / マイドリンク 0 | スコア 0 / 0、休肝ピル、`rest`。チップ欄は「よく飲む一杯を登録すると、ここを 1 回タップで記録できます」+ Button 副「登録」→ `/logs/my-drinks/new` |
| 1 タップ直後 | 杯数・g がサーバー応答後に旧値 → 新値へカウント（`--dur-state`、楽観更新しない。M-09）。0 → 1 なら休肝ピルがフェードアウト（M-18）、今日の週マスが下から満ちる（M-17）。`cheer` 300ms → `default`、切替の瞬間に上 4px → 0 を 1 回。トースト（M-23 / M-25）。動くのはこの 4 か所までで、同時に始まり 400ms で静止する |
| 取り消し | 数字が戻る（カウント）。0 に戻れば休肝ピルがフェードイン、週マスは即時に空へ。キャラは `default`（0 に戻ったら `rest`）。動きは数字とピルだけ |
| 1 タップ失敗 | トースト「保存できませんでした。もう一度試してください」（キャラなし）。数字は変えない |
| 取得失敗 | カード内に「読み込めませんでした」+ 再試行。ボタン群は使える |

### 操作と遷移

| 操作 | 結果 | タップ数（保存まで） |
|---|---|---|
| マイドリンクチップ | 保存 → トースト | **1** |
| 記録する → 保存 | `log-new`（初期ワイン、写真なし）→ 保存 → `/logs?highlight=<id>` | 2（入力内 1） |
| カメラ（または中央タブ）→ 撮影 → 使う → 保存 | `photo-edit` → `log-new` 写真付き → 保存 → 対象日の `log-day?highlight=<id>` | 3（撮影の OS 操作は含めない） |
| カメラ（または中央タブ）→ × / OS キャンセル | ホームに留まる。何も開かない | — |
| 今日カード | 今日の `/logs`（`log-day`） | — |
| 今週 › | `summary-week` | — |
| 週マス | その日の `/logs/:date`（X6。未来は無効） | — |
| 管理 | `mydrink-list` | — |

### キャラクター

- `default`（記録あり）/ `rest`（記録 0）72px、カード右下。装飾 `aria-hidden`
- 1 タップ直後 `cheer` 300ms + 上 4px → 0 を 1 回（[../character.md](../character.md) 6 章）。水面は上げない（トーストの `cheer` が担う）。reduced motion ではクロスフェードのみ
- 「記録する」押下ではキャラを動かさない（触った場所で起きる。カードのキャラは指から遠い）
- 文言は出さない（「今日は休肝」等のセリフ禁止。休肝はピルが示す）

## `summary-week` 週サマリー

| ルート | 親タブ | タブバー | ヘッダー | 主アクション |
|---|---|---|---|---|
| `/summary/week?date=YYYY-MM-DD` | home | 表示 | 「今週」（他週は「9月1日〜9月7日」） | なし（閲覧） |

入口: ホームの今日カード内「今週 ›」（H13）、月サマリーの週行。戻りはホーム。

```
┌──────────────────────────────────┐
│ ←  今週                    今月 ›│
├──────────────────────────────────┤
│ ‹  8/31 〜 9/6  ›                 │  週送り
│ ┌ Card ───────────────────────┐  │
│ │  12 杯   86.4 g   休肝 3 日  │  │  3 つの小スコア 24px
│ │  ▇ ▇ _ ▇ _ ▇ ▇  (棒グラフ)  │  │  日別 g。今日は primary、未来は薄い
│ │  月 火 水 木 金 土 日          │  │
│ └──────────────────────────────┘  │
│ 9/5 土  2 杯 ・ 28 g            › │  行 → log-day
│ 9/4 金  0 杯 ・ 休肝              │
│ …                                 │
├──────────────────────────────────┤
│ ホーム* セラー  (記録)  ノート  設定│
└──────────────────────────────────┘
```

| # | 要素 | 内容 | API |
|---|---|---|---|
| W1 | 週送り | 前週 / 次週（未来週は次へ進めない） | `GET /api/drink-logs/summary?period=week&date=` |
| W2 | 小スコア | 杯数・g・休肝日数（`dryDayCount`。未来日は含めない） | 同上 |
| W3 | 棒グラフ | 7 本。高さは g、軸ラベルなし（値は行で読む）。ライブラリは 3-06 で選定（軽量、SVG）。初回描画で棒が下から `--dur-enter` で伸びる（M-19。週送りでは再生しない、stagger なし） | `days[]` |
| W4 | 日別行 | 「日付 曜日 N 杯 ・ g」。0 件は「休肝」（`--rest`）。未来は「—」。タップで その日の `/logs/:date`（`log-day`） | 同上 |
| W5 | 今月 › | ヘッダー右 → `summary-month`（月サマリーへの唯一の入口） | — |

## `summary-month` 月サマリー

`/summary/month?date=YYYY-MM-DD`。入口は週サマリーの「今月 ›」だけ（戻りは週サマリー）。同じ Card 型。棒は日数分（28〜31 本、細い）。行は **週ごとに畳む**（「9/1〜9/7  12 杯 ・ 86.4 g ・ 休肝 3」→ タップで `summary-week`）。ヘッダー右は「今週」。

キャラクターはサマリー 2 画面には出さない（数値の画面）。
