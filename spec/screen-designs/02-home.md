## `home` ホーム

| ルート | 親タブ | タブバー | ヘッダー | 主アクション |
|---|---|---|---|---|
| `/` | home | 表示 | なし（画面内に「ホーム」+ 日付） | お酒を記録する（`log-new`） |

目的: 今日の状態を確認し、記録し、今週を振り返る。**記録の入口（お酒を記録する / 写真から記録 / マイドリンク）はこの画面に集約する**（日別 `log-day` には置かない。2026-09-06）。日別・週 / 月サマリーへの入口もここ。

並びは固定する（2026-09-08）。マイドリンクを今週より上へ移す指示は取り消す。マイドリンクは補助として控えめに置く。

1. 今日の記録サマリー
2. お酒を記録する操作
3. 今週の記録
4. マイドリンク

面はニューモーフィズムのまま。カードは浅い浮き（`--shadow-outset-sm`）、主ボタンは明確な浮き（`--shadow-primary`）。白い別面は重ねない。

```
┌──────────────────────────────────┐
│ ホーム                            │  画面内見出し。共通ヘッダーは出さない
│ 9月5日 (土)                       │  日付 13px/600 muted（JST）
│ ┌ 今日の記録 ──────── 未記録 ──┐  │  浅いカード。タップ → 今日の /logs
│ │  0杯 │ 純アルコール     [M] │  │  杯が主（40px + 単位近接）。g は従（24px）
│ │      │ 0.0 g                │  │  キャラ 72px はカード内右側。数値に重ねない
│ │ 今日はまだ記録がありません     │  │
│ └─────────────────────────────┘  │
│ [＋ お酒を記録する]               │  主ボタン全幅 → log-new（写真なし）
│ [📷 写真から記録]                 │  副ボタン全幅。中央タブと同じ撮影開始
│ ┌ 今週 ──────── 詳しく見る › ─┐  │  独立した浅いカード → summary-week
│ │ 月 火 水 木 金 土 日         │  │  ISO 週（月曜始まり、JST）
│ │  7  8  9 10 11 12 13        │  │  今日は日付の枠。記録ありは小さな印
│ │  ●  ○  ·  ·  ·  ·  ·        │  │  日付タップ → その日の /logs/:date（未来は無効）

│ └─────────────────────────────┘  │
│ マイドリンク                 管理  │
```

### 状態

| 状態 | 表示 |
|---|---|
| ローディング | 今日カード枠 + 今週カード枠のスケルトン。記録ボタンは使える。チップは 2 個の枠 |
| 未記録 / マイドリンク 0 | スコア 0 / 0.0 g、未記録ピル、補足「今日はまだ記録がありません」、`rest`。チップ欄は「よく飲む一杯を登録すると、ここを 1 回タップで記録できます」+ Button 副「登録」→ `/logs/my-drinks/new` |
| 飲酒記録あり | 実データの杯数・g、記録ありピル、補足「今日は N 杯記録しています」、`default` |
| 1 タップ直後 | 杯数・g がサーバー応答後に旧値 → 新値へカウント（`--dur-state`、楽観更新しない。M-09）。0 → 1 なら未記録ピルがフェードアウト（M-18）、今日の記録印が下から満ちる（M-17）。`cheer` 300ms → `default`、切替の瞬間に上 4px → 0 を 1 回。トースト（M-23 / M-25）。動くのはこの 4 か所までで、同時に始まり 400ms で静止する |
| 取り消し | 数字が戻る（カウント）。0 に戻れば未記録ピルがフェードイン、週の印は即時に空へ。キャラは `default`（0 に戻ったら `rest`）。動きは数字とピルだけ |
| 1 タップ失敗 | トースト「保存できませんでした。もう一度試してください」（キャラなし）。数字は変えない |
| 取得失敗 | カード内に「読み込めませんでした」+ 再試行。ボタン群は使える |

### キャラクター

- `default`（記録あり）/ `rest`（未記録）72px、カード内右側。装飾。タップはウィンクのみ（保存や遷移はしない）
- まばたき・登場時の視線・保存時の上下は [../character.md](../character.md) 6 章。待機の揺れやジャンプはしない
- 多量の横倒れは自動表示条件が未確定のため、`?mascotPreview=heavy` のプレビューだけ。飲み過ぎ判定は作らない
- ガイド中はホーム側の待機動きを止め、案内キャラ 1 体だけ動かす
- 文言は出さない（セリフ禁止）

## `summary-week` 週サマリー

| ルート | 親タブ | タブバー | ヘッダー | 主アクション |
|---|---|---|---|---|
| `/summary/week?date=YYYY-MM-DD` | home | 表示 | 「今週」（他週は「9月1日〜9月7日」） | なし（閲覧） |

入口: ホームの今週セクション「詳しく見る ›」（H13）、月サマリーの週行。戻りはホーム。

```
┌──────────────────────────────────┐
│ ←  今週                    今月 ›│
├──────────────────────────────────┤
│ ‹  8/31 〜 9/6  ›                 │  週送り
│ ┌ Card ───────────────────────┐  │
│ │  12 杯   86.4 g   休肝 3 日  │  │  3 つの小スコア 24px
│ │  ▇ ▇ _ ▇ _ ▇ ▇  (棒グラフ)  │  │  日別 g。今日は primary、未来は薄い
│ │  月 火 水 木 金 土 日          │  │
│ └──────────────────────────────┘  │
│ 9/5 土  2 杯 ・ 28 g            › │  行 → log-day
│ 9/4 金  0 杯 ・ 休肝              │
│ …                                 │
├──────────────────────────────────┤
│ ホーム* セラー  (記録)  ノート  設定│
└──────────────────────────────────┘
```

| # | 要素 | 内容 | API |
|---|---|---|---|
| W1 | 週送り | 前週 / 次週（未来週は次へ進めない） | `GET /api/drink-logs/summary?period=week&date=` |
| W2 | 小スコア | 杯数・g・休肝日数（`dryDayCount`。未来日は含めない） | 同上 |
| W3 | 棒グラフ | 7 本。高さは g、軸ラベルなし（値は行で読む）。**自前 SVG**（3-06。依存なし）。初回描画で棒が下から `--dur-enter` で伸びる（M-19。週送りでは再生しない、stagger なし） | `days[]` |
| W4 | 日別行 | 「日付 曜日 N 杯 ・ g」。0 件は「休肝」（`--rest`）。未来は「—」。タップで その日の `/logs/:date`（`log-day`） | 同上 |
| W5 | 今月 › | ヘッダー右 → `summary-month`（月サマリーへの唯一の入口） | — |

## `summary-month` 月サマリー

`/summary/month?date=YYYY-MM-DD`。入口は週サマリーの「今月 ›」だけ（戻りは週サマリー）。同じ Card 型。棒は日数分（28〜31 本、細い）。行は **週ごとに畳む**（「9/1〜9/7  12 杯 ・ 86.4 g ・ 休肝 3」→ タップで `summary-week`）。ヘッダー右は「今週」。

キャラクターはサマリー 2 画面には出さない（数値の画面）。
