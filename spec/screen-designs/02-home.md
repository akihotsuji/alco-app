## `home` ホーム

| ルート | 親タブ | タブバー | ヘッダー | 主アクション |
|---|---|---|---|---|
| `/` | home | 表示 | 「ホーム」 | 記録する（`log-new`） |

目的: 今日の状態を 1 秒で把握し、最短で記録に入る。

```
┌──────────────────────────────────┐
│              ホーム               │
├──────────────────────────────────┤
│ 9月5日 土曜                        │  日付 13px/600 muted（JST）
│ ┌ 今日 ───────────────────────┐  │
│ │  2              28          │  │  スコア 40px。杯 / g
│ │  杯             g 純アルコール │  │
│ │  月 火 水 木 金 土 日          │  │
│ │  ■  ■  □  ■  □  ▣  □       │  │  ■ 記録あり ▣ 今日 □ なし
│ └───────────────────[Mascot]──┘  │  キャラ 72px が右下から覗く
│                                  │
│ [      記録する      ] [📷]       │  主ボタン + カメラ円 52px
│                                  │
│ マイドリンク                 管理  │
│ [赤ラベル 125ml] [ハイボール]     │  チップ 1 タップ記録
│                                  │
├──────────────────────────────────┤
│ ホーム* セラー  (記録)  ノート  設定│
└──────────────────────────────────┘
```

### 要素表

| # | 要素 | 種別 | 内容・挙動 | データ / API |
|---|---|---|---|---|
| H1 | 日付 | テキスト | 「9月5日 土曜」。JST | クライアント |
| H2 | 今日カード | Card | タップで `summary-week` | `GET /api/drink-logs/summary?period=day` |
| H3 | 杯数 | スコア 40px | `totalCount`。0 のとき「0」 | 同上 |
| H4 | 純アルコール | スコア 40px | `displayAlcoholGrams(totalAlcoholG)`、単位「g 純アルコール」 | 同上 |
| H5 | 休肝ピル | ピル（`--rest`） | 記録 0 のとき杯数の右に「休肝」。0 でないときは非表示 | `totalCount === 0` |
| H6 | 週マス | 7 マス | 月〜日（ISO 週、JST）。記録あり = primary 塗り inset、今日 = 枠線 2px primary、未来 = 薄く。タップで `summary-week` | `GET /api/drink-logs/summary?period=week` |
| H7 | キャラクター | Mascot 72px | カード右下、外へ 12px はみ出す。記録あり `default`、0 `rest` | H3 |
| H8 | 記録する | Button 主 | `/logs/new` | — |
| H9 | カメラ | Button 副（円 52px、`camera`） | `/logs/new?camera=1`（開いた直後に撮影へ） | — |
| H10 | マイドリンク見出し + 管理 | テキスト + リンク | 「管理」→ `/logs/my-drinks` | — |
| H11 | マイドリンクチップ | Chip（最大 4、`sortOrder` 順） | ラベル「名前 量ml」（40 文字までで省略）。**1 タップで保存、遷移なし** | `GET /api/my-drinks`、`POST /api/my-drinks/:id/log` |
| H12 | トースト | Toast | 「記録しました  取り消す」5 秒。`cheer` 付き | `DELETE /api/drink-logs/:id` |

### 状態

| 状態 | 表示 |
|---|---|
| ローディング | カード枠 + ボタン外形のスケルトン。チップは 2 個の枠 |
| 記録 0 / マイドリンク 0 | スコア 0 / 0、休肝ピル、`rest`。チップ欄は「よく飲む一杯を登録すると、ここを 1 回タップで記録できます」+ Button 副「登録」→ `/logs/my-drinks/new` |
| 1 タップ直後 | 杯数・g が即時更新（サーバー応答後。楽観更新しない）、`cheer` 300ms → `default`、トースト |
| 取り消し | 数字が戻る。キャラは `default`（0 に戻ったら `rest`） |
| 1 タップ失敗 | トースト「保存できませんでした。もう一度試してください」（キャラなし）。数字は変えない |
| 取得失敗 | カード内に「読み込めませんでした」+ 再試行。ボタン群は使える |

### 操作と遷移

| 操作 | 結果 | タップ数（保存まで） |
|---|---|---|
| マイドリンクチップ | 保存 → トースト | **1** |
| 記録する → 保存 | `log-new`（初期ワイン）→ 保存 → `/logs` | 2（入力内 1） |
| カメラ → 撮影 → 使う → 保存 | `log-new` 写真付き | 4 |
| 今日カード / 週マス | `summary-week` | — |
| 管理 | `mydrink-list` | — |

### キャラクター

- `default`（記録あり）/ `rest`（記録 0）72px、カード右下。装飾 `aria-hidden`
- 1 タップ直後 `cheer` 300ms。`prefers-reduced-motion` では即時
- 文言は出さない（「今日は休肝」等のセリフ禁止。休肝はピルが示す）

## `summary-week` 週サマリー

| ルート | 親タブ | タブバー | ヘッダー | 主アクション |
|---|---|---|---|---|
| `/summary/week?date=YYYY-MM-DD` | home | 表示 | 「今週」（他週は「9月1日〜9月7日」） | なし（閲覧） |

```
┌──────────────────────────────────┐
│ ←  今週                    今月 ›│
├──────────────────────────────────┤
│ ‹  8/31 〜 9/6  ›                 │  週送り
│ ┌ Card ───────────────────────┐  │
│ │  12 杯   86.4 g   休肝 3 日  │  │  3 つの小スコア 24px
│ │  ▇ ▇ _ ▇ _ ▇ ▇  (棒グラフ)  │  │  日別 g。今日は primary、未来は薄い
│ │  月 火 水 木 金 土 日          │  │
│ └──────────────────────────────┘  │
│ 9/5 土  2 杯 ・ 28 g            › │  行 → log-day
│ 9/4 金  0 杯 ・ 休肝              │
│ …                                 │
├──────────────────────────────────┤
│ ホーム* セラー  (記録)  ノート  設定│
└──────────────────────────────────┘
```

| # | 要素 | 内容 | API |
|---|---|---|---|
| W1 | 週送り | 前週 / 次週（未来週は次へ進めない） | `GET /api/drink-logs/summary?period=week&date=` |
| W2 | 小スコア | 杯数・g・休肝日数（`dryDayCount`。未来日は含めない） | 同上 |
| W3 | 棒グラフ | 7 本。高さは g、軸ラベルなし（値は行で読む）。ライブラリは 3-06 で選定（軽量、SVG） | `days[]` |
| W4 | 日別行 | 「日付 曜日 N 杯 ・ g」。0 件は「休肝」（`--rest`）。未来は「—」。タップで `/logs/:date` | 同上 |
| W5 | 今月 | ヘッダー右 → `summary-month` | — |

## `summary-month` 月サマリー

`/summary/month?date=YYYY-MM-DD`。同じ Card 型。棒は日数分（28〜31 本、細い）。行は **週ごとに畳む**（「9/1〜9/7  12 杯 ・ 86.4 g ・ 休肝 3」→ タップで `summary-week`）。ヘッダー右は「今週」。

キャラクターはサマリー 2 画面には出さない（数値の画面）。
