## `settings-account-delete` アカウントを削除

| ルート | 親タブ | タブバー | ヘッダー | 主アクション |
|---|---|---|---|---|
| `/settings/account/delete` | settings（確認済み） / なし（未確認） | 隠す | 「アカウントを削除」。戻る | アカウントとデータを削除 |

認証必須。年齢確認は不要。未ログインは `/login?redirect=/settings/account/delete`。

```
┌──────────────────────────────────┐
│ ‹  アカウントを削除               │
├──────────────────────────────────┤
│ 飲酒記録、セラーのボトル、        │
│ テイスティングノート、マイドリンク、│
│ 保存した写真、アカウント情報を    │
│ 削除します。ご意見・ご要望の本文と│
│ 添付画像は、どなたからのものか    │
│ 分からない形で残します。          │
│ 削除後は元に戻せません。          │
│ Googleアカウント自体や、端末の    │
│ 写真アプリにある写真は削除されません。│
│                                  │
│ 削除を受け付けると、このアカウント│
│ は利用できなくなります。保存データ│
│ の削除は順次行います。バックアップ│
│ 等の保管期間についてはプライバシー│

│     確認しました                  │
│                                  │

│ [                    (表示)]     │
```

### 要素表

| # | 要素 | 種別 | 内容・挙動 | データ / API |
|---|---|---|---|---|
| D1 | 見出し | ヘッダー | 「アカウントを削除」 | — |
| D2 | 本文 | テキスト | 「飲酒記録、セラーのボトル、テイスティングノート、マイドリンク、保存した写真、アカウント情報を削除します。削除後は元に戻せません。Googleアカウント自体や、端末の写真アプリにある写真は削除されません。」 | — |
| D3 | 補足 | テキスト 14px muted | 「削除を受け付けると、このアカウントは利用できなくなります。保存データの削除は順次行います。バックアップ等の保管期間についてはプライバシーポリシーをご確認ください。」リンクは `/privacy?from=settings` | — |
| D4 | 復元不可の確認 | チェックボックス | 「データを復元できないことを確認しました」。初期 OFF | — |
| D5 | パスワード | Input | `hasPassword` のとき。`autocomplete=current-password`。表示切替あり | ボディ `password` |
| D6 | Googleで本人確認する | Button 副 | Google のみ（`hasPassword` が false）のとき。押下で Google 再ログイン。`callbackURL` は本画面。戻っても自動削除しない | `signIn.social` |
| D7 | アカウントとデータを削除 | Button 破壊的 | 本人確認を終え、D4 が ON のときだけ押せる。送信中は無効＋「削除を受け付けています…」。二重送信しない。キーボード表示時も SaveBar で操作できる | `POST /api/me/account-deletion` |
| D8 | キャンセル | リンク | 履歴戻り。無ければ設定（確認済み）または `/age`（未確認）。削除しない | — |
| D9 | 別アカウント警告 | テキスト | Google 再ログイン後の userId が開始時と違うとき。「別のアカウントでログインしたため、削除手続きを中止しました。」D7 は押せない | sessionStorage |

確認用文字列の入力や確認ダイアログの重ね掛けは置かない。

### 状態

| 状態 | 表示 |
|---|---|
| 初期 | D4 OFF。D7 無効 |
| 本人確認待ち（Google） | D6 を出す。再ログイン前は D7 無効 |
| 送信中 | D7 無効、「削除を受け付けています…」 |
| 受付成功 | `/account-deleted` へ replace |
| 通信失敗（応答なし・成否不明） | 「通信が途切れたため、受付結果を確認できません」。成功断定しない |
| 誤パスワード / 再認証不足 | 画面内に「本人確認が必要です。パスワードを確認するか、Googleで再ログインしてください。」削除しない |
| レート制限 | 「しばらく待ってから試してください」 |
| 入力不備 | 画面内に汎用文。削除しない |
| 別アカウントで戻った | D9。手続き破棄 |

### 操作と遷移

| 操作 | 結果 |
|---|---|
| 戻る / キャンセル | 削除しない |
| D4 ON + パスワード正しい + D7 | 202 → `/account-deleted` |
| D4 ON + Google 再ログイン 5 分以内 + D7 | 同上 |
| 送信中の再タップ | 無視 |

フォーカス・読み上げ・縮小モーションは [00-common.md](00-common.md) と [motion-design.md](../motion-design.md) の共通規約。

## `account-deleted` 削除受付完了

| ルート | 親タブ | タブバー | ヘッダー | 主アクション |
|---|---|---|---|---|
| `/account-deleted` | なし | なし | なし | ログインへ |

認証不要。新しい公開 API は無い。バックグラウンド処理が残る時点では完了断定しない。

```
┌──────────────────────────────────┐
│ アカウント削除を受け付けました。  │
│ このアカウントは利用できません。  │
│ 保存した写真などの削除を進めています。│
│                                  │
│ [ ログインへ ]                   │
└──────────────────────────────────┘
```

### 要素表

| # | 要素 | 種別 | 内容・挙動 | データ / API |
|---|---|---|---|---|
| C1 | 見出し | テキスト | 「アカウント削除を受け付けました」 | — |
| C2 | 本文 | テキスト | 「このアカウントは利用できません。保存した写真などの削除を進めています。」「全データの削除が完了しました」は出さない | — |
| C3 | ログインへ | Button 主 / リンク | `/login` | — |

削除要求は端末を閉じてもサーバー側で継続する。

## 受け入れチェック

- [ ] 設定のアカウント節に「アカウントを削除」があり、ログアウトとは間隔がある。破壊的スタイル
- [ ] `/settings/account/delete` に指定本文・補足・チェック・最終ボタンがある
- [ ] チェック OFF または本人確認前は最終ボタンを押せない
- [ ] パスワードユーザーはパスワード入力、Google のみは再ログイン。戻っても自動削除しない
- [ ] 別 Google アカウントで戻ったら手続きを破棄する
- [ ] キャンセル・戻るでは削除しない
- [ ] 送信中は「削除を受け付けています…」で二重送信しない
- [ ] 通信失敗は画面内に残す。応答喪失は成功断定しない
- [ ] キーボード表示時も確認ボタンを操作できる
- [ ] 受付後は `/account-deleted`。完了断定文は出さない。ログインへ戻れる
- [ ] 年齢確認未完了・未満拒否から削除画面へ辿れる。削除に年齢確認を要求しない
- [ ] テーマ等の個人データを含まない設定を一括破棄しない
- [ ] キャラクターを出さない。飲酒助長の文言が無い
