## `note-new` ノートを作成

| ルート | 親タブ | タブバー | ヘッダー | 主アクション |
|---|---|---|---|---|
| `/notes/new?bottleId=&camera=1` | notes | **隠す** | ← 「ノートを作成」 | 保存する |

目的: **写真を撮って、評価と一言を付ける**。4 欄はあとから書ける。

```
┌──────────────────────────────────┐
│ ←  ノートを作成                    │
├──────────────────────────────────┤
│ 写真                        1 / 6 │
│ [📷 撮る][96×120][96×120] →       │  横スクロール。先頭は撮るタイル
│ ボトル                            │
│ [ サンプル赤（セラー）        × ›] │  選択済み。× で解除し手入力へ
│   または  銘柄名 [        ] 種類 [▼]│  ボトル未選択時に表示
│ 飲んだ日   今日                ›  │
│ 評価                              │
│  ★ ★ ★ ★ ☆   4.5   [−][＋]      │  0.5 刻み。星タップで整数、± で 0.5
│ 一言                              │
│ [                              ] │  任意 ≦200（taste に保存。詳細で先頭に出す）
│ 詳しく書く                     ▼  │  折りたたみ: 外観 / 香り / 味わい / 余韻（各 ≦2000）
├──────────────────────────────────┤
│ [          保存する          ]   │
└──────────────────────────────────┘
```

### 要素表

| # | 要素 | 種別 | 内容・挙動 | データ / API |
|---|---|---|---|---|
| N1 | 写真ストリップ | 写真タイル（撮る）+ サムネ 96×120 × 最大 6 | 「撮る」→ `photo-edit`（4:5、`table`、**キャラ合成トグルあり**）。サムネ長押しで並び替え（MVP は「先頭にする」メニューでよい）。サムネタップ → 編集 / 削除。`?camera=1` で自動起動 | `POST /api/photos` ×N |
| N2 | ボトル | 行（ピッカー） | 「選ぶ ›」→ ダイアログ（検索 + 棚サムネ行、貯蔵庫含む）。選択で銘柄名・種類を **表示**（サーバーがスナップショット）。`?bottleId=` で事前選択 | `bottleId` |
| N3 | 銘柄名 / 種類 | Input + Chip | ボトル未選択時のみ表示・必須 | `drinkName`, `drinkType` |
| N4 | 飲んだ日 | 行 → `date` | 既定今日。未来不可 | `tastedOn` |
| N5 | 評価 | 星 5 + 数値 + ステッパー | 1.0〜5.0、0.5 刻み。既定 **未選択**（保存に必須） | `ratingX10` |
| N6 | 一言 | Input（1 行） | **`taste` 欄そのもの**の 1 行表示。別列は作らない | `taste` |
| N7 | 詳しく書く | 折りたたみ | 開くと `taste` が複数行 Textarea に広がり、外観 / 香り / 余韻の Textarea が追加される（各 ≦2000） | `appearance`, `aroma`, `taste`, `finish` |
| N8 | 保存する | Button 主 | 無効: 評価未選択 / 銘柄名空（ボトル未選択時） / 写真アップロード中 | `POST /api/tasting-notes`（`photoIds` 含む） |

### 状態

| 状態 | 表示 |
|---|---|
| `camera=1` | `photo-edit` が先に開く。× でフォームへ |
| 7 枚目 | 「撮る」タイルを無効化し「写真は 6 枚までです」 |
| 成功 | 作成した `note-detail` へ `replace`。トースト「保存しました」（`cheer`） |
| 失敗 | インライン汎用文 |
| 戻る（未保存） | 確認。未紐付け写真を削除 |

### バリデーション

| 項目 | 規則 |
|---|---|
| 評価 | 10〜50、5 刻み（必須） |
| 銘柄名 | ボトル未選択時 1〜100 |
| 飲んだ日 | `YYYY-MM-DD`、未来不可 |
| 4 欄 | 各 ≦2000 |
| 写真 | ≦6 |

## `note-detail` ノート詳細

| ルート | 親タブ | タブバー | ヘッダー | 主アクション |
|---|---|---|---|---|
| `/notes/:noteId` | notes | 表示 | ← 銘柄名 右「編集」 | 編集 |

```
┌──────────────────────────────────┐
│ ←  サンプル赤                 編集 │
├──────────────────────────────────┤
│ ┌──────────────────────────────┐  │
│ │        写真 4:5（横スワイプ） │  │  幅一杯（350×437）。ドット 3 個
│ └──────────────────────────────┘  │
│ ★★★★☆ 4.5        2026年8月1日    │  評価 20px + 日付
│ [🍾 セラーのボトル ›]              │  紐付きがあれば行。消費済みは「貯蔵庫の」
│                                  │
│ 味わい   酸がきれいで…             │  値のある欄だけ。順は 外観 / 香り / 味わい / 余韻
│ 香り     赤系果実と…               │
│ …                                │
├──────────────────────────────────┤
│ ホーム  セラー  (記録)  ノート* 設定│
└──────────────────────────────────┘
```

| # | 要素 | 内容 | API |
|---|---|---|---|
| V1 | 写真カルーセル | 4:5、`scroll-snap`、ドットインジケータ。タップで全画面。写真なしはカルーセル自体を出さない | `photos[]` |
| V2 | 評価 + 日付 | 星（塗り = `--primary`）+ 数値 + 日付 | `ratingX10`, `tastedOn` |
| V3 | ボトル行 | `bottleId` があれば → `/cellar/:bottleId`。削除済み（null）なら出さない | `bottleId` |
| V4 | 4 欄 | 見出し 13px muted + 本文 16px。空欄は出さない。すべて空なら「まだ書いていません」 | 4 欄 |
| V5 | 編集 | `/notes/:noteId/edit` | — |

キャラクターは出さない。

## `note-edit`

`/notes/:noteId/edit`。`note-new` と同じ。差分: 初期値、`PATCH`、写真の追加・削除・並び（`PATCH /api/photos/:id` の `sortOrder`）、下部「このノートを削除」（確認、danger）→ 一覧。ボトル解除（× → 手入力に戻すと `drinkName` / `drinkType` 必須）。

## 受け入れチェック（5-02 / 5-03 / 5-04）

- [ ] 一覧が **2 列写真グリッド 4:5**。写真なしは種類アイコン。文字は写真の下
- [ ] 「+」→ 撮影から。写真は最大 6、`table` プリセット、キャラ合成トグル
- [ ] ボトルピッカー（貯蔵庫含む）。`?bottleId=` 事前選択。未選択なら銘柄名・種類必須
- [ ] 評価 0.5 刻み必須。一言 = `taste`。4 欄は折りたたみ
- [ ] 詳細: カルーセル + ドット、ボトル行、空欄は非表示
- [ ] 編集で写真追加・削除・先頭化、削除確認
- [ ] 他人の `:noteId` / `bottleId` は `not-found`
