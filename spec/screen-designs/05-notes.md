### 要素表

| # | 要素 | 種別 | 内容・挙動 | データ / API |
|---|---|---|---|---|
| L1 | 検索 | Chip → Input | 銘柄（親記録の識別）部分一致。プレースホルダ「銘柄・メモで検索」 | `q` |
| L2 | 種類 | Chip → ダイアログ | 単一選択 | `drinkType` |
| L3 | 評価 | Chip「★4 以上」 | トグル。ON で `ratingX10Min=40`。選択中は見た目と `aria-pressed`。aria-label は未選択「評価4以上で絞り込む」、選択中「評価4以上の絞り込みを解除」。再タップで解除。4.0 未満を除外 | `ratingX10Min` |
| L4 | カード | 横並びカード | 左にサムネ（4:5 小さめ）、右に銘柄（主・最大 2 行省略）・飲んだ日・星評価・短い感想（`taste`）。**写真に文字を重ねない** | `items[]`（`taste` を一覧に含める） |
| L5 | 写真なし | 同じ枠の inset | 中央に種類アイコン。レイアウトは崩れない | — |
| L6 | 日付 / 評価 / 感想 | テキスト | 日付は今日／同年は月日／過去年は年月日。星 + 数値。感想は 2 行省略（無ければ行を出さない）。写真 2 枚以上は `images` + 枚数 | `ratingX10`, `tastedOn`, `photoCount`, `taste` |
| L7 | カードタップ | — | `/notes/:noteId` | — |
| L8 | `bottleId` 指定時 | ヘッダー | ← 銘柄名（ボトル詳細へ戻る）。一覧はそのボトルのみ | `GET /api/tasting-notes?bottleId=` |
| L9 | （廃止） | — | FAB「＋ ノート作成」と空状態の作成ボタンは置かない。作成は中央タブの記録フォーム | — |

## `note-new` / `note-edit`（廃止）

ルートは作らない。`/notes/new` は `/logs/new` へリダイレクト（`bottleId` / `from` は引き継ぐ。`fromLog` は捨てる）。`/notes/:noteId/edit` は親記録の `log-edit` へ（取れなければ `not-found`）。

## `note-detail` ノート詳細（読み取りビュー）

| ルート | 親タブ | タブバー | ヘッダー | 主アクション |
|---|---|---|---|---|
| `/notes/:noteId` | notes | 表示 | ← 銘柄名 右「編集」 | 親記録の `log-edit` |

```
┌──────────────────────────────────┐
│ ←  サンプル赤                 編集 │
├──────────────────────────────────┤
│ ┌──────────────────────────────┐  │
│ │        写真 4:5（横スワイプ） │  │
│ └──────────────────────────────┘  │
│ サンプル赤                         │
│ Googleで調べる                     │
│ ★★★★☆ 4.5        2026年8月1日    │
│ 125ml ・ 12% ・ 12.0 g             │  親記録の量（スタブ移行も同じ）
│ 2020                               │
│ [🍾 セラーのボトル ›]              │
│                                  │
│ 味わい   酸がきれいで…             │
│ 香り     赤系果実と…               │
├──────────────────────────────────┤
│ ホーム  セラー  (記録)  ノート* 設定│
└──────────────────────────────────┘
```

| # | 要素 | 内容 | API |
|---|---|---|---|
| V1 | 写真カルーセル | 4:5、`scroll-snap`、ドットインジケータ。タップで全画面。写真なしはカルーセル自体を出さない | `photos[]` |
| V1s | Googleで調べる | 本文の品名直下。一覧カードには出さない | 表示中のノート |
| V2 | 評価 + 日付 | 星 + 数値 + 日付。ヴィンテージがあれば続けて出す | `ratingX10`, `tastedOn`, `vintage` |
| V2c | 記録の量 | 親記録の量・度数・g。スタブ移行の行も同じ形式で出す | `drinkLog` |
| V2b | 識別 | 生産者・生産国・品種があればテキスト（親記録の識別） | `producer`, `origin`, `variety` |
| V3 | ボトル行 | `bottleId` があれば → `/cellar/:bottleId`。削除済みなら出さない | `bottle` |
| V4 | 4 欄 | 見出し 13px muted + 本文 16px。空欄は出さない。すべて空なら「まだ書いていません」 | 4 欄 |
| V5 | 編集 | 親記録の `/logs/entries/:logId/edit`。ノート単独の編集画面は開かない | `drinkLogId` |

キャラクターは出さない。他人・不在の `:noteId` は `not-found`。

## 受け入れチェック（閲覧専用 + 記録へ統合）

- [ ] 一覧が **横並びカード**（銘柄が主。写真・日付・評価・短い感想）。写真なしでも崩れない。0 件だけ空状態。検索 0 件は未登録と別表示
- [ ] 右下 FAB「＋ ノート作成」と空状態の「ノートを作成」は無い。ヘッダー右の「＋ 作成」も無い
- [ ] 空状態の補助は「味や感想は、記録するときに残せます」
- [ ] `/notes/new` は `log-new` へリダイレクトする。`/notes/:noteId/edit` は親記録の `log-edit` へ行く（取れなければ `not-found`）
- [ ] 詳細は読み取りビュー。量・度数・g は親記録。編集は記録編集。識別は親記録。4 欄の空欄は非表示
- [ ] 詳細: カルーセル + ドット、ボトル行、Googleで調べる（一覧カードには出さない）
- [ ] 他人の `:noteId` / `bottleId` は `not-found`
- [ ] ボトル詳細のノート節は一覧のみ（「書く ›」が無い）
