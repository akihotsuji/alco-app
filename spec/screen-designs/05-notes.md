## `note-new` ノートを作成

| ルート | 親タブ | タブバー | ヘッダー | 主アクション |
|---|---|---|---|---|
| `/notes/new?bottleId=&fromLog=` | notes | **隠す** | ← 「ノートを作成」 | ノートを保存 |

目的: **お酒の評価・香り・味わいを残し、振り返る**。写真は任意。4 欄はあとから書ける。

```
┌──────────────────────────────────┐
│ ←  ノートを作成                    │
│     香りや味わいを残す             │
├──────────────────────────────────┤
│ [セラーから選ぶ] [新しく入力]      │  新規の入口。役割はノートのまま
│ 写真 任意                    0 / 6 │
│ [ 写真を撮る ] [ 写真を選ぶ ]      │  小さなボタン。明示タップのみ。確定で即サムネ（photo-edit なし）
│ [✦ 写真から入れました]             │  読み取り帯
│ 品名 必須                         │
│ [ 例：Planeta                    ] │  ボトル選択時も表示・修正可
│ Googleで調べる                    │  品名直下。保存前でも可
│ 種類 必須                         │
│ [ 種類を選択                   ›] │  セレクト。全 12 種
│ お酒の情報（任意）              ▾  │  品種・生産者・国と関連付け。評価の前に延々出さない
│ テイスティング日                    │
│ [ 今日                         ›] │  過去年は年月日。fromLog は記録日。写真があれば撮影日
│ 評価 必須                         │
│  ★ ★ ★ ★ ☆                 4.2  │  星はスライダーに連動。右は数値表示
│  [ − ] [━━━━━━━━━●────] [ ＋ ]   │  スライダー 1.0〜5.0 step 0.1 が主。左右の ± で 0.1 増減。未選択を 3.5 にしない
│ ひとこと 任意                      │
│ [                              ] │  taste。詳細で先頭に出す
│ 詳しく書く                     ▼  │  詳細な感想。商品情報とは分ける
├──────────────────────────────────┤
│ [        ノートを保存        ]   │  無効時「必須項目を入力してください」
└──────────────────────────────────┘
```

## `note-edit`

`/notes/:noteId/edit`。`note-new` と同じ。差分: 上部は写真・品名・年号・種類の要約。「お酒の情報を編集」で商品情報を展開（初期は閉じる。検証エラー時だけ開く）。初期値、`PATCH`、写真の追加・削除・並び（`PATCH /api/photos/:id` の `sortOrder`）、下部「このノートを削除」（確認、danger。保存バーから距離を取る）→ 一覧。ボトル解除（× → 手入力に戻すと `drinkName` / `drinkType` 必須）。未変更なら「変更はありません」。

## 受け入れチェック（5-02 / 5-03 / 5-04）

- [ ] 一覧が **横並びカード**（銘柄が主。写真・日付・評価・短い感想）。写真なしでも崩れない。0 件だけ空状態。「まだ他のノートはありません」は 1 件以上で出さない。検索 0 件は未登録と別表示
- [ ] 右下 FAB「＋ ノート作成」→ フォーム（撮影しない）。ヘッダー右の「＋ 作成」は無い。写真はフォーム先頭の「写真を撮る」「写真を選ぶ」のみ起動。OS 確定の直後に `photo-edit` を開かず中央 4:5 のサムネが積まれる（「使う」は出ない）。位置直しはサムネの「編集」。最大 6、設定どおりキャラ合成
- [ ] 写真確定で品名・種類・識別 4 項目を空欄へ入れ、上げ直しの再読取では直前の AI 値を上書きする（ボトル選択中は種類を変えない）。失敗しても保存できる
- [ ] 品種 / 生産者 / 生産国は「お酒の情報」にまとめる（ヴィンテージ空 = 未登録。表示で NV と書かない）
- [ ] 新規は「セラーから選ぶ / 新しく入力」。関連付けは見えるボタン。選ばずに入力できる。`?bottleId=` 事前選択。`?fromLog=` は記録の識別・日付・写真（未紐付け複製）を引き継ぐ（評価は未選択）。開栓 / 詳細から来たノートはボトル写真を複製する。ボトル詳細・開栓後だけ上部に「対象：○○」。後選択・解除で手入力の品名・種類・感想を消さない。未選択なら品名・種類必須。共有ボトルに紐づいてもノートは個人
- [ ] 編集上部は要約。「お酒の情報を編集」で展開。品名・種類のあと飲んだ日→評価→ひとこと→詳しく書く
- [ ] 新規・編集・詳細の品名付近に「Googleで調べる」。編集は折りたたみ閉じていても使え、開くと二重表示しない。一覧カードには出さない
- [ ] 評価 0.1 刻み必須。スライダーが主で星が連動して埋まり、数値も出る。スライダー左右の ± で 0.1 増減できる。星タップでも整数を選べる。キーボード操作はスライダー。未選択を 0 点で保存しない。ひとこと = `taste`。4 欄は折りたたみ（削除しない）
- [ ] 初期表示で未操作欄に赤いエラーを並べない。保存無効時は短い説明。保存中は二重送信しない。失敗・撮影キャンセルでも入力を保持。ノート作成時に飲酒記録は作らない
- [ ] 詳細: カルーセル + ドット、ボトル行、識別・空欄は非表示
- [ ] 編集で写真追加・削除・先頭化、削除確認
- [ ] 保存ボタンの水位線と即遷移、トーストの `cheer` 水面、空状態の 1 回出現が共通部品どおり（ノート固有の演出が無い）
- [ ] 他人の `:noteId` / `bottleId` は `not-found`
