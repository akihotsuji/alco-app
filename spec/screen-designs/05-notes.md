## `note-list` ノート一覧（カード）

| ルート | 親タブ | タブバー | ヘッダー | 主アクション |
|---|---|---|---|---|
| `/notes?bottleId=&q=&drinkType=&ratingX10Min=` | notes | 表示 | 「ノート」（`bottleId` 時は ← 銘柄名）右「＋ 作成」 | 作成（ヘッダー → `note-new`。撮影しない） |

```
┌──────────────────────────────────┐
│           ノート          ＋ 作成 │
│ 香りや味わいを振り返る             │
├──────────────────────────────────┤
│ [ 銘柄・メモで検索 ]               │
│ [種類 ▼] [★4 以上]                │
│ 最近のノート                       │
│ ┌ カード ─────────────────────┐  │
│ │[写真] 銘柄名                 ›│  │  銘柄が主。写真なしは種類アイコン
│ │       日付  星評価            │  │  実データ。モックの銘柄は埋め込まない
│ │       短い感想（taste）       │  │
│ └──────────────────────────────┘  │
│ （1 件以上あるとき空案内は出さない） │
├──────────────────────────────────┤
│ ホーム  セラー  (記録)  ノート* 設定│
└──────────────────────────────────┘
```

## `note-new` ノートを作成

| ルート | 親タブ | タブバー | ヘッダー | 主アクション |
|---|---|---|---|---|
| `/notes/new?bottleId=&fromLog=` | notes | **隠す** | ← 「ノートを作成」 | ノートを保存 |

目的: **お酒の評価・香り・味わいを残し、振り返る**。写真は任意。4 欄はあとから書ける。

```
┌──────────────────────────────────┐
│ ←  ノートを作成                    │
│     香りや味わいを残す             │
├──────────────────────────────────┤
│ 写真 任意                    0 / 6 │
│ [ 写真を撮る ] [ 写真を選ぶ ]      │  小さなボタン。明示タップのみ
│ [✦ 写真から入れました]             │  読み取り帯
│ 品名 必須                         │
│ [ 例：Planeta                    ] │  ボトル選択時も表示・修正可
│ 種類 必須                         │
│ [ 種類を選択                   ›] │  セレクト。全 7 種
│ セラーのボトルと関連付ける（任意）  │  種類の次。大きなカードにしない
│ ヴィンテージ / 品種                 │
│ [ NV ] [                         ] │  常時。空 = NV
│ 生産者 / 生産国                    │
│ テイスティング日                    │
│ [ 今日                         ›] │  fromLog は記録日。写真があれば撮影日
│ 評価 必須                         │
│  ★ ★ ★ ★ ☆                      │  星タップが主。0.5 は数値入力
│  4.5（数値。キーボード操作可）      │  未選択を 0 として保存しない
│ ひとこと 任意                      │
│ [                              ] │  taste。詳細で先頭に出す
│ 詳しく書く                     ▼  │  外観 / 香り / 味わい / 余韻（削除しない）
├──────────────────────────────────┤
│ [        ノートを保存        ]   │  無効時「必須項目を入力してください」
└──────────────────────────────────┘
```

### 要素表

| # | 要素 | 種別 | 内容・挙動 | データ / API |
|---|---|---|---|---|
| N1 | 写真（任意） | 小さなボタン + サムネ × 最大 6 | **フォーム先頭**。「写真を撮る」→ `photo-edit`（4:5、`table`、**キャラ合成トグルあり**）。「写真を選ぶ」→ 保存済み写真。枚数・並べ替え（先頭にする）・削除は維持。**自動起動しない**（`?camera=1` も無視）。「使う」でキャラ合成前の JPEG から品名・種類・識別 4 項目を空欄へ入れる。撮影日をテイスティング日の既定にする（`fromLog` と編集では維持） | `POST /api/photos` ×N。`POST /api/tasting-notes/recognize` |
| N2 | ボトル関連付け | 任意の行（種類の次） | 「セラーのボトルと関連付ける（任意）」。未選択はコンパクト。選択済みは名前 + 変更 + 解除。ボトル詳細・開栓後だけ上部に「対象：○○」。後から選んでも手入力の品名・種類・感想を上書きしない。解除でも消さない。未選択のまま保存可。`?fromLog=` は記録の識別・日付を先に入れる | `bottleId` |
| N3 | 品名 / 種類 | Input + セレクト | **常に表示**。ボトル未選択時は必須。ボトル選択時も修正できる（サーバーはボトルありなら品名・種類のスナップショットを正とする既存規則） | `drinkName`, `drinkType` |
| N3b | 識別 | ヴィンテージ / 品種 / 生産者 / 生産国 | **常時表示**。任意。ヴィンテージは 1800〜2100 / 空 = NV。他は ≦100。AI とボトル選択は空欄にだけ入れる | `vintage`, `variety`, `producer`, `origin` |
| N4 | テイスティング日 | ラベル上 + 行 → `date` | 既定今日。`fromLog` は記録の `drunkOn`。写真があれば撮影日（ユーザー未操作時。`fromLog` / 編集は維持）。未来不可 | `tastedOn` |
| N5 | 評価 | 星 5 + 数値 | 1.0〜5.0、0.5 刻み。既定 **未選択**（0 として保存しない）。星タップが主（整数。同じ星の再タップで +0.5、5.0 は上限）。数値欄（step 0.5）でキーボード・読み上げ操作。大きく離れた ± は置かない | `ratingX10` |
| N6 | ひとこと（任意） | Input（1 行） | **`taste` 欄そのもの**の 1 行表示。別列は作らない | `taste` |
| N7 | 詳しく書く | 折りたたみ | 既存 4 欄は削除しない。開くと `taste` が複数行 Textarea に広がり、外観 / 香り / 余韻の Textarea が追加される（各 ≦2000） | `appearance`, `aroma`, `taste`, `finish` |
| N8 | ノートを保存 | Button 主 | 無効: 評価未選択 / 品名空（ボトル未選択時） / 種類未選択（ボトル未選択時） / 写真アップロード中・失敗中。無効時「必須項目を入力してください」。初期の未操作欄に赤いエラーを並べない。保存中は二重送信防止。失敗時は入力保持 | `POST /api/tasting-notes`（`photoIds` 含む） |

### 状態

| 状態 | 表示 |
|---|---|
| `camera=1` | **無視**。フォームだけ開き、撮影は始めない |
| 7 枚目 | 「撮る」「選ぶ」タイルを無効化し「写真は 6 枚までです」 |
| 成功 | 作成した `note-detail` へ即 `replace`（N8 は M-04〜M-06 の loading / 即遷移 / 失敗の戻し）。トースト「保存しました」（`cheer` + 水面 M-25）。`haptic("success")` |
| 失敗 | インライン汎用文（オフラインなら X4） |
| 戻る（未保存） | 確認。未紐付け写真を削除 |

モーションは共通部品のもの（押下 M-01 / M-02、チップ M-31、ダイアログ M-13 / M-30、トースト M-23〜M-25）だけを使い、ノート固有の演出は置かない（[../motion-design.md](../motion-design.md)）。

## `note-edit`

`/notes/:noteId/edit`。`note-new` と同じ。差分: 初期値、`PATCH`、写真の追加・削除・並び（`PATCH /api/photos/:id` の `sortOrder`）、下部「このノートを削除」（確認、danger）→ 一覧。ボトル解除（× → 手入力に戻すと `drinkName` / `drinkType` 必須）。

## 受け入れチェック（5-02 / 5-03 / 5-04）

- [ ] 一覧が **横並びカード**（銘柄が主。写真・日付・評価・短い感想）。写真なしでも崩れない。0 件だけ空状態。「まだ他のノートはありません」は 1 件以上で出さない。検索 0 件は未登録と別表示
- [ ] ヘッダー右「＋ 作成」→ フォーム（撮影しない）。FAB は無い。写真はフォーム先頭の「写真を撮る」「写真を選ぶ」のみ起動。最大 6、`table` プリセット、キャラ合成トグル
- [ ] 写真確定で品名・種類・識別 4 項目を空欄へ入れる（ボトル選択中は種類を変えない）。失敗しても保存できる
- [ ] ヴィンテージ / 品種 / 生産者 / 生産国が常時ある（ヴィンテージ空 = NV）
- [ ] セラー関連付けは種類の次の任意行。選ばずに入力できる。`?bottleId=` 事前選択。`?fromLog=` は記録の識別・日付を引き継ぐ（評価は未選択。写真はコピーしない）。ボトル詳細・開栓後だけ上部に「対象：○○」。後選択・解除で手入力の品名・種類・感想を消さない。未選択なら品名・種類必須
- [ ] 評価 0.5 刻み必須。星タップが主。数値でも示しキーボード操作可。未選択を 0 点で保存しない。ひとこと = `taste`。4 欄は折りたたみ（削除しない）
- [ ] 初期表示で未操作欄に赤いエラーを並べない。保存無効時は短い説明。保存中は二重送信しない。失敗・撮影キャンセルでも入力を保持。ノート作成時に飲酒記録は作らない
- [ ] 詳細: カルーセル + ドット、ボトル行、識別・空欄は非表示
- [ ] 編集で写真追加・削除・先頭化、削除確認
- [ ] 保存ボタンの水位線と即遷移、トーストの `cheer` 水面、空状態の 1 回出現が共通部品どおり（ノート固有の演出が無い）
- [ ] 他人の `:noteId` / `bottleId` は `not-found`
