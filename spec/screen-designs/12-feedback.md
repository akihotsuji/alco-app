# 12 ご意見・ご要望

実装: 設定からの問い合わせ。[features/feedback.md](../features/feedback.md)。入口は [06-settings.md](06-settings.md) S17。

キャラクターは出さない。切り抜き・キャラ合成・AI 読み取りはしない。

## `settings-feedback` ご意見・ご要望

| ルート | 親タブ | タブバー | ヘッダー | 主アクション |
|---|---|---|---|---|
| `/settings/feedback` | settings | 隠す | 「ご意見・ご要望」。戻る（設定） | 送信する |

認証必須。年齢未確認は `/age?redirect=/settings/feedback`。未ログインは `/login?redirect=/settings/feedback`。

```
┌──────────────────────────────────┐
│ ‹  ご意見・ご要望                 │
├──────────────────────────────────┤
│ 種類                              │
│ (改善案*) (不具合) (その他)        │  チップ 3 択。既定は改善案
│                                  │
│ 内容                         必須 │
│ ┌──────────────────────────────┐ │
│ │ 使いにくい点や欲しい機能      │ │  Textarea。1〜2000
│ └──────────────────────────────┘ │
│ 残り 2000 文字                    │
│                                  │
│ 画像                         任意 │
│ [撮る] [選ぶ]                     │  最大 3。切り抜き・キャラなし
│ ┌────┐ ┌────┐                   │  サムネ + 外す
│ │    │ │    │                   │
│ └────┘ └────┘                   │
│                                  │
│ 返信をお約束するものでは         │
│ ありません。退会後も、どなた     │
│ からのものか分からない形で       │
│ 改善の参考として残します。       │
│                                  │
│ ┌──────── 送信する ────────┐    │  SaveBar
└──────────────────────────────────┘
```

### 要素表

| # | 要素 | 種別 | 内容・挙動 | データ / API |
|---|---|---|---|---|
| F1 | 種類 | チップ列 3 択（`fieldset` / `legend`） | 「改善案」（既定）/「不具合」/「その他」。1 つ必須 | `category` |
| F2 | 内容 | Textarea | 1〜2000 文字。前後空白は trim。空なら送信不可。残数を出す | `body` |
| F3 | 画像 | 撮る / 選ぶ + サムネ | 任意。最大 3 枚。`input type=file accept=image/*`。撮るは `capture="environment"`。選ぶは `capture` なし・複数可。端末で長辺 1280 に縮小して JPEG。切り抜き・キャラ合成・photo-edit は開かない。サムネは `<img alt="">`。各サムネに「外す」 | `photos` 0〜3 |
| F4 | 注意 | テキスト | 「返信をお約束するものではありません。退会後も、どなたからのものか分からない形で改善の参考として残します。」 | — |
| F5 | 送信する | SaveBar 主 | ラベル「送信する」/ 送信中「送信中」。空の本文または送信中は無効。成功はトースト「送りました」（キャラなし）→ `/settings` | `POST /api/feedback` |
| F6 | 戻る | ヘッダー左 | 履歴。無ければ `/settings` | — |

### 状態

| 状態 | 表示 |
|---|---|
| 初期 | 種類は改善案。本文空。画像なし。送信不可 |
| 画像処理中 | 追加ボタンを無効。「読み込み中」 |
| 送信中 | SaveBar 無効 + 「送信中」 |
| 検証エラー | 欄の近くに汎用文（文字数など） |
| 429 | SaveBar 付近「しばらく待ってから試してください」 |
| その他失敗 | 「送信できませんでした。もう一度試してください」 |

キャラクターは出さない。成功トーストも cheer なし。

### 遷移

| 操作 | 行き先 |
|---|---|
| 設定 S17 | 本画面 |
| 戻る / 送信成功 | `/settings` |
| 未ログイン | `/login?redirect=/settings/feedback` |
| 年齢未確認 | `/age?redirect=/settings/feedback` |

## 受け入れチェック

- [ ] 設定「このアプリ」の先頭が「ご意見・ご要望」で、本画面へ行く
- [ ] 種類 3 択、本文必須、画像は任意で最大 3。切り抜き・キャラ合成が走らない
- [ ] 空の本文では送信できない
- [ ] 成功で「送りました」→ 設定。キャラは出ない
- [ ] 注意文に返信なしと退会後の匿名保持がある
- [ ] タブバーが隠れ、戻ると設定に戻る
