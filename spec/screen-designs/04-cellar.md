# 04 セラー（陳列・貯蔵庫・追加・詳細・消費）

実装: 4-02（追加・詳細・編集）/ 4-03（消費・貯蔵庫・開栓）/ 4-04（陳列）/ 4-06（切り抜き）/ 4-07（ラベル読み取り）。写真の撮影・編集・切り抜きは [07-photo-capture.md](07-photo-capture.md)。

モック: [cellar-shelf.png](../wireframes/mocks/cellar-shelf.png)（1 本ずつ）、[cellar-by-type.png](../wireframes/mocks/cellar-by-type.png)（種類ごと）、[cellar-archive.png](../wireframes/mocks/cellar-archive.png)、[cellar-new.png](../wireframes/mocks/cellar-new.png)（ラベル読み取り後）、[cellar-detail.png](../wireframes/mocks/cellar-detail.png)、[cellar-consume.png](../wireframes/mocks/cellar-consume.png)

2026-09-05（2 回目）のオーナー決定: 棚は **地色の上にガラス風の棚板**、ボトルは **切り抜き**（背景除去を MVP へ）。**種類ごと / 1 本ずつ**の表示切替。**ラベルの AI 読み取り**（Cloudflare Workers AI）はセラーのみ。

## 概念

```
   追加（撮って登録）                 消費（飲み終えた）
 ─────────────────►  セラー（棚）  ─────────────────►  貯蔵庫（アーカイブ）
                     sealed / opened                    consumed
                          ▲                                 │
                          └────────── セラーに戻す（undo） ──┘
                                            │
                              その日の記録に 1 杯を追加（任意）→ log-day
```

- **1 行 = 1 本**。登録時の本数 N はサーバーが N 行に展開する（上限 12）
- 開栓（`sealed → opened`）はサブ操作。棚に残る
- 消費は常に 1 本。ダイアログで「今日の記録に 1 杯追加」を選べる（既定 ON）
- 写真は 2:3 に切り、`cellar` プリセットを掛け、**端末内で背景除去**して透過 WebP で保存する（`photos.kind = cutout`）。除去できないときは長方形 JPEG（`kind = photo`）にフォールバックし、棚では角 8px の写真として載せる
- ラベル読み取り: 撮影直後に **切り抜く前の 2:3 JPEG** を `POST /api/bottles/recognize` に送り、返ってきた候補を空のフィールドにだけ入れる。ユーザーが確認して保存する（自動保存しない）

### 貯蔵庫（`consumed`）のとき

- T3 は **「ノートを書く」**（Button 主）に置き換える。T4 / T5 は出さない
- ピル「消費（9/5）」の右に「この日の記録 ›」→ `/logs/2026-09-05`
- Button 副「セラーに戻す」を T6 の上に置く。タップで即時 `POST /api/bottles/:id/restore` → 棚へ戻り、トースト「セラーに戻しました」。**記録は消さない**（消費 undo とは別）
- 写真は減彩しない（詳細では原色）

## `bottle-edit` ボトルを編集

`/cellar/:bottleId/edit`。`bottle-new` と同じレイアウト。差分:

- 本数ステッパーは無い（1 行 = 1 本）
- 状態は編集できない（詳細のボタンで操作）。開栓日・消費日は詳細から
- 写真の付け替え: 削除 → 撮る。`PATCH` の `photoIds`
- 保存 → `PATCH /api/bottles/:id` → 詳細
- 下部テキストボタン「このボトルを削除」→ 確認ダイアログ「ノートは残ります。記録のボトル名は残ります」（danger）→ `DELETE` → `/cellar`。**貯蔵庫の本も削除できる**

## 陳列の写真（4-04 / 4-06 の実装メモ）

| 段の構成（1 本ずつ） | 390px で 3 列（列幅 = (390 − 40 − 16×2) / 3 ≒ 106px）。480px 以上で 4 列 |
| 段の構成（種類ごと） | 1 種類 = 1 段、横スクロール。列幅 72px、間隔 22px。ゴースト見出し 44px / 700 `--shelf-ghost`、段の左上 −18px に重ねる |
| 落ち影 | cutout の足元に楕円の影（幅 80%、高さ 6px、黒 25%）を画像側に焼き込む（`photo-edit`。棚板の上に立って見える） |
