## `auth-login` ログイン

| ルート | 親タブ | タブバー | ヘッダー | 主アクション |
|---|---|---|---|---|
| `/login` | なし | なし | なし（カード内見出し） | ログイン |

```
┌──────────────────────────────────┐
│                                  │
│           [Mascot default 120]    │
│              alco-app             │  ワードマーク 13px/600 muted
│ ┌ カード ──────────────────────┐ │
│ │ ログイン                      │ │  24px/600
│ │ メール                        │ │
│ │ [                          ] │ │  Input
│ │ パスワード                    │ │
│ │ [                    (表示)] │ │  Input + 表示切替
│ │ [        ログイン         ]   │ │  Button 主
│ │      アカウントを作成         │ │  primary 文字リンク → /signup
│ └──────────────────────────────┘ │
│                                  │
└──────────────────────────────────┘
```

### 要素表

| # | 要素 | 種別 | 内容・挙動 | データ / API |
|---|---|---|---|---|
| L1 | キャラクター | Mascot `default` 120px | 装飾（`aria-hidden`）。カード上 24px | — |
| L2 | ワードマーク | テキスト | 「alco-app」。ロゴ画像は作らない | — |
| L3 | メール | Input `type=email` `autocomplete=email` | 必須。前後空白は trim | — |
| L4 | パスワード | Input `type=password` `autocomplete=current-password` | 必須。右端に表示/非表示（`eye`） | — |
| L5 | ログイン | Button 主 | 押下で無効化 + 「ログイン中」 | `signIn.email` |
| L6 | アカウントを作成 | リンク | `/signup`（`redirect` クエリは引き継ぐ） | — |

### 状態

| 状態 | 表示 |
|---|---|
| 初期 | 空のフォーム。メールにフォーカスしない（iOS のキーボード自動表示を避ける） |
| 送信中 | ボタン無効、「ログイン中」 |
| エラー | カード上部に汎用文「メールまたはパスワードが正しくありません」。どちらが誤りかは出さない |
| レート制限 | 「しばらく待ってから試してください」 |
| 成功 | `redirect`（安全な相対パスのみ）または `/` へ `replace` |

### バリデーション（クライアント。正はサーバー）

- メール: 空 / 形式不正で送信不可
- パスワード: 空で送信不可。文字数の下限は表示しない（存在推測を避ける）

### キャラクター

`default` 120px、常時。エラー時もポーズは変えない（叱らない）。

## `auth-signup` アカウント作成

| ルート | 親タブ | タブバー | ヘッダー | 主アクション |
|---|---|---|---|---|
| `/signup` | なし | なし | なし | 登録する |

ログインと同じ型。差分のみ:

| # | 要素 | 内容 |
|---|---|---|
| S1 | 見出し | 「アカウント作成」 |
| S2 | 表示名 | Input、任意、1〜40 文字。Better Auth `name` |
| S3 | メール | 必須 |
| S4 | パスワード | 必須。8 文字以上（Better Auth 既定）。`autocomplete=new-password`。強度メーターは置かない |
| S5 | 登録する | Button 主 → 成功後は自動ログインして `/` |
| S6 | ログインへ | リンク → `/login` |

- 招待コード欄は置かない（確定）
- 既存メールのエラーも汎用文「登録できませんでした。入力内容を確認してください」（存在推測を避ける）
- 年齢確認・利用規約は Phase 8（MVP では出さない）
