### 状態

| 状態 | 表示 |
|---|---|
| 初期 | 空のフォーム。メールにフォーカスしない（iOS のキーボード自動表示を避ける）。キーがあるときは確認待ちで送信不可 |
| 送信中 | ボタン無効、「ログイン中」 |
| エラー | カード上部に汎用文「メールまたはパスワードが正しくありません」。どちらが誤りかは出さない |
| 確認読込失敗 | 「確認の読み込みに失敗しました。時間をおいて再度お試しください」。スキップボタンは置かない |
| レート制限 | 「しばらく待ってから試してください」 |
| 再設定後 | `?reset=1` のときカード上部に「パスワードを変更しました。ログインしてください。」 |
| OAuth 失敗 | カード上部に「ログインできませんでした。時間をおいて再度お試しください」。`error` クエリは残さない |
| 成功 | `redirect`（安全な相対パスのみ）または `/` へ `replace`。未確認なら `/age` |

### バリデーション（クライアント。正はサーバー）

- メール: 空 / 形式不正で送信不可
- パスワード: 空で送信不可。文字数の下限は表示しない（存在推測を避ける）

### キャラクター

`default` 120px、常時。エラー時もポーズは変えない（叱らない）。

## `auth-signup` アカウント作成

| ルート | 親タブ | タブバー | ヘッダー | 主アクション |
|---|---|---|---|---|
| `/signup` | なし | なし | なし | 登録する |

ログインと同じ型。差分のみ:

| # | 要素 | 内容 |
|---|---|---|
| S1 | 見出し | 「アカウント作成」 |
| S2 | 表示名 | Input、任意、1〜40 文字。Better Auth `name` |
| S3 | メール | 必須 |
| S4 | パスワード | 必須。8 文字以上（Better Auth 既定）。`autocomplete=new-password`。強度メーターは置かない |
| S5 | 登録する | Button 主 → 成功後は自動ログインして `/age`（`redirect` があれば `/age?redirect=`） |
| S6 | ログインへ | リンク → `/login` |
| S7 | 法務同意 | 必須チェック。文言「利用規約とプライバシーポリシーに同意する」。リンクはチェックのラベル外（`/terms?from=signup` / `/privacy?from=signup`）。未チェックでは送信不可。サーバーも拒否 | `acceptedLegal` + `legalVersion`（[../features/legal.md](../features/legal.md)） |
| S8 | 区切り | 「または」 |
| S9 | Google で続行 | Button 副。未チェックまたは確認未完了では無効。新規は `/age`。同じメールのパスワードユーザーはリンクしない。`signIn.social`（`requestSignUp: true`）。同じ Turnstile トークン |
| S10 | ボット対策 | Turnstile ウィジェット。規約チェックの下、主ボタンの上。キーがあるときだけ。スキップは置かない | `GET /api/config` → `x-captcha-response` |

- 招待コード欄は置かない（確定）
- 既存メールのエラーも汎用文「登録できませんでした。入力内容を確認してください」（存在推測を避ける）
- 登録停止（`SIGNUPS_CLOSED`）はカード上部「現在、新規登録を停止しています」。招待ではない（8-06。[../features/usage-monitoring.md](../features/usage-monitoring.md)）
- S7 の同意は 20 歳以上であることの表明を含む。専用の生年月日確認は `auth-age`（8-02。[../features/age-verification.md](../features/age-verification.md)）

### 状態

ログインと同じ送信中・確認読込失敗・レート制限に加え:

| 状態 | 表示 |
|---|---|
| エラー | カード上部「登録できませんでした。入力内容を確認してください」。既存メールも同じ |
| 登録停止 | カード上部「現在、新規登録を停止しています」。招待コード欄は出さない。フォームは残す（公開 API に停止フラグは出さない） |
| 成功 | `/age`（`redirect` があれば引き継ぐ）へ `replace` |

## `auth-age` 年齢確認

| ルート | 親タブ | タブバー | ヘッダー | 主アクション |
|---|---|---|---|---|
| `/age` | なし | なし | なし（カード内見出し） | 確認する |

ログインと同じ型（`.auth-page`）。未ログインは `/login?redirect=/age`。確認済みが来たら `redirect`（安全な相対パス）または `/`。

```
┌──────────────────────────────────┐
│                                  │
│           [Mascot default 120]    │
│              酒のしおり           │
│ ┌ カード ──────────────────────┐ │
│ │ 年齢確認                      │ │
│ │ 酒類の記録のため、20歳以上の  │ │
│ │ 方のみ利用できます。          │ │
│ │ 生年月日                      │ │
│ │ [        1990-01-15        ] │ │  type=date
│ │ [        確認する         ]   │ │
│ │         ログアウト            │ │
│ └──────────────────────────────┘ │
└──────────────────────────────────┘
```

拒否時は同じカードで見出しと本文だけ替える。生年月日は残さない。

### 要素表

| # | 要素 | 種別 | 内容・挙動 | データ / API |
|---|---|---|---|---|
| A1 | キャラクター | Mascot `default` 120px | 装飾（`aria-hidden`）。エラー時もポーズは変えない | — |
| A2 | ワードマーク | テキスト | 「酒のしおり」 | — |
| A3 | 見出し | テキスト | 確認: 「年齢確認」。拒否: 「ご利用いただけません」 | — |
| A4 | 説明 | テキスト | 確認: 「酒類の記録のため、20歳以上の方のみ利用できます。」拒否: 「20歳未満の方は本サービスをご利用いただけません。」飲酒を勧める文言は置かない | — |
| A5 | 生年月日 | Input `type=date` `autocomplete=bday` | 確認状態のみ。必須。`min=1900-01-01`、`max` は JST 今日 | `birthOn` |
| A6 | 確認する | Button 主 | 押下で無効化 + 「確認中」。未満は拒否状態へ。成功は `redirect` または `/` | `POST /api/me/age-verification` |
| A7 | ログアウト | Button 副 / リンク | `endSession`。確認ダイアログは出さない（まだ本機能に入っていない） | Better Auth `signOut` |
| A8 | 生年月日を修正 | Button 副 | 拒否状態のみ。確認フォームへ戻す（再入力可） | — |

### 状態

| 状態 | 表示 |
|---|---|
| 初期 | 空の日付。フォーカスしない |
| 送信中 | ボタン無効、「確認中」 |
| 形式エラー | カード上部「生年月日を確認してください」 |
| 拒否（未満） | A3 / A4 を拒否文に。A5 / A6 を隠し A8 を出す |
| 成功 | `redirect` または `/` へ `replace` |
| 確認済みで再訪 | フォームを出さず `redirect` または `/` |

### バリデーション（クライアント。正はサーバー）

- 空 / 形式不正 / 未来日は送信不可
- 20 歳かどうかの判定はクライアントに頼らない（送ってサーバーが計算する）

### キャラクター

`default` 120px、常時。拒否時も叱らない。

## `auth-forgot-password` パスワード再設定（メール）

| ルート | 親タブ | タブバー | ヘッダー | 主アクション |
|---|---|---|---|---|

```

│ │         ログインへ            │ │
│ └──────────────────────────────┘ │
```

## `auth-reset-password` 新しいパスワード

| ルート | 親タブ | タブバー | ヘッダー | 主アクション |
|---|---|---|---|---|
| `/reset-password` | なし | なし | なし | 変更する |

ログインと同じ型。`GuestOnly` に入れない。到着時に `token` / `error` をメモリへ移し、アドレスバーから消す。

```
┌──────────────────────────────────┐
│           [Mascot default 120]    │
│              酒のしおり           │
│ ┌ カード ──────────────────────┐ │
│ │ 新しいパスワード              │ │
│ │ パスワード（8文字以上）       │ │
│ │ [                    (表示)] │ │
│ │ パスワード（確認）            │ │
│ │ [                    (表示)] │ │
│ │ [        変更する         ]   │ │
│ │         ログインへ            │ │
│ └──────────────────────────────┘ │
└──────────────────────────────────┘
```

トークン無し・`error=INVALID_TOKEN` は同じ無効状態。見出し「リンクが無効です」。

### 要素表

| # | 要素 | 種別 | 内容・挙動 | データ / API |
|---|---|---|---|---|
| R1 | キャラクター | Mascot `default` 120px | 装飾。無効時も `default` | — |
| R2 | ワードマーク | テキスト | 「酒のしおり」 | — |
| R3 | 見出し | テキスト | 入力: 「新しいパスワード」。無効: 「リンクが無効です」 | — |
| R4 | 説明 | テキスト | 入力: 「リンクの案内に沿って、新しいパスワードを設定してください。」無効: 「有効期限切れか、すでに使われたリンクです。もう一度メールからやり直してください。」 | — |
| R5 | パスワード | Input `autocomplete=new-password` | 必須。8 文字以上。表示切替あり。無効時は隠す | — |
| R6 | パスワード（確認） | Input `autocomplete=new-password` | 必須。R5 と一致。表示切替あり。無効時は隠す | — |
| R7 | 変更する | Button 主 | 押下で無効化 + 「変更中」。成功は `/login?reset=1` へ `replace` | `resetPassword` |
| R8 | ログインへ | リンク | `/login`。無効時は「再設定メールを送る」→ `/forgot-password` | — |

### 状態

| 状態 | 表示 |
|---|---|
| 初期（トークンあり） | 空の 2 欄。フォーカスしない |
| 送信中 | ボタン無効、「変更中」 |
| 不一致 | 「パスワードが一致しません」 |
| トークン無効 | R3 / R4 を無効文。R5〜R7 を隠す |
| レート制限 | 「しばらく待ってから試してください」 |
| 成功 | `/login?reset=1` |

### バリデーション（クライアント。正はサーバー）

- 8〜128 文字。確認欄が一致しないと送信不可
- 強度メーターは置かない

### キャラクター

`default` 120px、常時。無効時も叱らない。
