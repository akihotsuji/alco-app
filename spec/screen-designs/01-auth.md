## `auth-login` ログイン

| ルート | 親タブ | タブバー | ヘッダー | 主アクション |
|---|---|---|---|---|
| `/login` | なし | なし | なし（カード内見出し） | ログイン |

```
┌──────────────────────────────────┐
│                                  │
│           [Mascot default 120]    │
│              酒のしおり           │  ワードマーク 13px/600 muted
│ ┌ カード ──────────────────────┐ │
│ │ ログイン                      │ │  24px/600
│ │ メール                        │ │
│ │ [                          ] │ │  Input
│ │ パスワード                    │ │
│ │ [                    (表示)] │ │  Input + 表示切替
│ │ [        ログイン         ]   │ │  Button 主
│ │      アカウントを作成         │ │  primary 文字リンク → /signup
│ └──────────────────────────────┘ │
│                                  │
└──────────────────────────────────┘
```

### 要素表

| # | 要素 | 種別 | 内容・挙動 | データ / API |
|---|---|---|---|---|
| L1 | キャラクター | Mascot `default` 120px | 装飾（`aria-hidden`）。カード上 24px | — |
| L2 | ワードマーク | テキスト | 「酒のしおり」。ロゴ画像は作らない | — |
| L3 | メール | Input `type=email` `autocomplete=email` | 必須。前後空白は trim | — |
| L4 | パスワード | Input `type=password` `autocomplete=current-password` | 必須。右端に表示/非表示（`eye`） | — |
| L5 | ログイン | Button 主 | 押下で無効化 + 「ログイン中」 | `signIn.email` |
| L6 | アカウントを作成 | リンク | `/signup`（`redirect` クエリは引き継ぐ） | — |

### 状態

| 状態 | 表示 |
|---|---|
| 初期 | 空のフォーム。メールにフォーカスしない（iOS のキーボード自動表示を避ける） |
| 送信中 | ボタン無効、「ログイン中」 |
| エラー | カード上部に汎用文「メールまたはパスワードが正しくありません」。どちらが誤りかは出さない |
| レート制限 | 「しばらく待ってから試してください」 |
| 成功 | `redirect`（安全な相対パスのみ）または `/` へ `replace` |

### バリデーション（クライアント。正はサーバー）

- メール: 空 / 形式不正で送信不可
- パスワード: 空で送信不可。文字数の下限は表示しない（存在推測を避ける）

### キャラクター

`default` 120px、常時。エラー時もポーズは変えない（叱らない）。

## `auth-signup` アカウント作成

| ルート | 親タブ | タブバー | ヘッダー | 主アクション |
|---|---|---|---|---|
| `/signup` | なし | なし | なし | 登録する |

ログインと同じ型。差分のみ:

| # | 要素 | 内容 |
|---|---|---|
| S1 | 見出し | 「アカウント作成」 |
| S2 | 表示名 | Input、任意、1〜40 文字。Better Auth `name` |
| S3 | メール | 必須 |
| S4 | パスワード | 必須。8 文字以上（Better Auth 既定）。`autocomplete=new-password`。強度メーターは置かない |
| S5 | 登録する | Button 主 → 成功後は自動ログインして `/age`（`redirect` があれば `/age?redirect=`） |
| S6 | ログインへ | リンク → `/login` |
| S7 | 法務同意 | 必須チェック。文言「利用規約とプライバシーポリシーに同意する」。リンクはチェックのラベル外（`/terms?from=signup` / `/privacy?from=signup`）。未チェックでは送信不可。サーバーも拒否 | `acceptedLegal` + `legalVersion`（[../features/legal.md](../features/legal.md)） |

- 招待コード欄は置かない（確定）
- 既存メールのエラーも汎用文「登録できませんでした。入力内容を確認してください」（存在推測を避ける）
- S7 の同意は 20 歳以上であることの表明を含む。専用の生年月日確認は `auth-age`（8-02。[../features/age-verification.md](../features/age-verification.md)）

## `auth-age` 年齢確認

| ルート | 親タブ | タブバー | ヘッダー | 主アクション |
|---|---|---|---|---|
| `/age` | なし | なし | なし（カード内見出し） | 確認する |

ログインと同じ型（`.auth-page`）。未ログインは `/login?redirect=/age`。確認済みが来たら `redirect`（安全な相対パス）または `/`。

```
┌──────────────────────────────────┐
│                                  │
│           [Mascot default 120]    │
│              酒のしおり           │
│ ┌ カード ──────────────────────┐ │
│ │ 年齢確認                      │ │
│ │ 酒類の記録のため、20歳以上の  │ │
│ │ 方のみ利用できます。          │ │
│ │ 生年月日                      │ │
│ │ [        1990-01-15        ] │ │  type=date
│ │ [        確認する         ]   │ │
│ │         ログアウト            │ │
│ └──────────────────────────────┘ │
└──────────────────────────────────┘
```

拒否時は同じカードで見出しと本文だけ替える。生年月日は残さない。

### 要素表

| # | 要素 | 種別 | 内容・挙動 | データ / API |
|---|---|---|---|---|
| A1 | キャラクター | Mascot `default` 120px | 装飾（`aria-hidden`）。エラー時もポーズは変えない | — |
| A2 | ワードマーク | テキスト | 「酒のしおり」 | — |
| A3 | 見出し | テキスト | 確認: 「年齢確認」。拒否: 「ご利用いただけません」 | — |
| A4 | 説明 | テキスト | 確認: 「酒類の記録のため、20歳以上の方のみ利用できます。」拒否: 「20歳未満の方は本サービスをご利用いただけません。」飲酒を勧める文言は置かない | — |
| A5 | 生年月日 | Input `type=date` `autocomplete=bday` | 確認状態のみ。必須。`min=1900-01-01`、`max` は JST 今日 | `birthOn` |
| A6 | 確認する | Button 主 | 押下で無効化 + 「確認中」。未満は拒否状態へ。成功は `redirect` または `/` | `POST /api/me/age-verification` |
| A7 | ログアウト | Button 副 / リンク | `endSession`。確認ダイアログは出さない（まだ本機能に入っていない） | Better Auth `signOut` |
| A8 | 生年月日を修正 | Button 副 | 拒否状態のみ。確認フォームへ戻す（再入力可） | — |

### 状態

| 状態 | 表示 |
|---|---|
| 初期 | 空の日付。フォーカスしない |
| 送信中 | ボタン無効、「確認中」 |
| 形式エラー | カード上部「生年月日を確認してください」 |
| 拒否（未満） | A3 / A4 を拒否文に。A5 / A6 を隠し A8 を出す |
| 成功 | `redirect` または `/` へ `replace` |
| 確認済みで再訪 | フォームを出さず `redirect` または `/` |

### バリデーション（クライアント。正はサーバー）

- 空 / 形式不正 / 未来日は送信不可
- 20 歳かどうかの判定はクライアントに頼らない（送ってサーバーが計算する）

### キャラクター

`default` 120px、常時。拒否時も叱らない。
