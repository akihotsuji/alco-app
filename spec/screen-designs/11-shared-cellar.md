# 11 セラー共有（選択・招待・設定・参加・競合）

実装は [features/shared-cellar.md](../features/shared-cellar.md) と本ファイル。既存棚・追加・詳細の差し込みは [04-cellar.md](04-cellar.md) が正。下部タブは増やさない。

モックは質感確認用。要素表と食い違えば要素表が正。

---

## 共通

- 本文・入力 16px、補足 14px 以上、タップ 44px 以上
- 名称・人数・チェックはテキストでも理解できる。色やアバターだけで共有状態を表さない
- 招待・退出・削除確認の長文は左揃え。対象と結果を先に出す
- 通知はヘッダー直下の通常フロー。FAB・タブ・保存バーを隠さない
- 成功演出は本人の保存 / 参加時だけ。reduced motion を尊重する
- ボトムシートは既存 `app-sheet-panel`（フォーカス、Escape / 戻る、閉じた後の復帰、スクロールロック）

## `cellar-switcher` セラー選択（ルートなし。ボトムシート）

| ルート | 親タブ | タブバー | ヘッダー | 主アクション |
|---|---|---|---|---|
| なし（`/cellar` と `/cellar/archive` の選択行） | cellar | 表示 | — | セラーを選ぶ |

棚ヘッダーの直下に 1 行。共有アイコンをヘッダーへ詰め込まない。

### 選択行（C14）

| # | 要素 | 種別 | 内容・挙動 | データ |
|---|---|---|---|---|
| C14 | セラー選択行 | 行（44px） | 左: 現在名 + ▾。右: 人アイコン + 「N人」または「自分だけ」。タップでシート | `GET /api/cellars` |
| C15 | 更新のお知らせ | 通常フロー 1 行 | 必要なときだけ。棚を覆わない | revision 同期 |

個人: 「自分のセラー ▾」「自分だけ」。共有: 「ふたりのセラー ▾」「2人」。

```
┌──────────────────────────────────┐
│ [貯蔵庫]   セラー  12 本      [⧉]│
│ ふたりのセラー ▾            👤 2人│  C14
│ セラーを更新しました              │  C15（必要なとき）
├──────────────────────────────────┤
│ [種類ごと|1本ずつ*] …             │
```

### シート

| # | 要素 | 種別 | 内容・挙動 | データ |
|---|---|---|---|---|
| S1 | 見出し | タイトル | 「表示するセラー」 | — |
| S2 | 自分のセラー | 行 | 名称「自分のセラー」+「自分だけ」。選択中はチェック（テキスト「選択中」も） | kind=personal |
| S3 | 共有セラー | 行 | 名称 + 「N人」。未参加なら出さない | kind=shared |
| S4 | セラーを共有する | Button 副 | 未参加のとき。`/cellar/share` | — |
| S5 | 共有設定 | Button 副 | 参加済み。メンバーにも出す。`/cellar/share/settings` | — |

- 通常は最後に表示したセラーを開く（`localStorage` `cellar.selectedId`）。権限喪失時は個人へ
- 切替時は別セラーの棚を一瞬も出さない。選択先のスケルトン。検索・表示形式・スクロールはセラーごと
- 別タブの選択変更で、開いているフォームの保存先は変えない
- 貯蔵庫も同じセラー。戻る操作で個人セラーへ飛ばない

| 状態 | 表示 |
|---|---|
| ローディング | 選択行は「セラー ▾」+ 人数なし |
| 権限喪失 | 共有データを隠し、個人セラーへ。シートに「参加していません」 |
| 通信失敗 | C15「最新の変更を確認できません。再試行」 |

## `cellar-join` 招待を受けて参加

| ルート | 親タブ | タブバー | ヘッダー | 主アクション |
|---|---|---|---|---|
| `/join` | — | なし | なし（公開） / 認証後は戻る | ログインして参加 / 参加する |

トークンは URL フラグメント `#t=`。処理後にアドレスバーと sessionStorage から除去する。

### 未ログイン

| # | 要素 | 内容 |
|---|---|---|
| J1 | 説明 | サービスの短い一般説明。「招待リンクからの参加です」 |
| J2 | 主操作 | 「ログインして参加」。`/login?redirect=/join`。ボトル・写真・メンバー名は出さない |

### 認証後・参加可能

| # | 要素 | 内容 |
|---|---|---|
| J3 | 確認 | 「○○に参加しますか？」 |
| J4 | 招待者 | 招待者の表示名 |
| J5 | 共有対象 | ボトル・写真・棚と貯蔵庫は共有。飲酒記録とノートは共有されない。記録に保存したコピーは脱退後も残る |
| J6 | 参加 | 「参加する」。確定後その共有セラーを開く。本人の既存ボトルは移らない |

| 状態 | 表示 |
|---|---|
| 使用済 / 期限切 / 無効 | 「この招待リンクは利用できません。招待した人に新しいリンクを作ってもらってください。」 |
| 既にそのセラー | 「セラーを開く」 |
| 別の共有に参加中 | 自動脱退しない。「共有設定」への導線 |
| 定員 | 利用不可と同じ文（存在を漏らさない） |

参加確定前にボトル一覧を見せない。

## `cellar-share-settings` 共有設定

| ルート | 親タブ | タブバー | ヘッダー | 主アクション |
|---|---|---|---|---|
| `/cellar/share/settings` | cellar | 隠す | 戻る「共有設定」 | — |

順: 名称 → 参加者 → 招待 → ボトル移動 → 最近の変更 → 危険操作。退出とボトル削除を同じ場所に並べない。

| # | 要素 | 種別 | 内容 | 権限 |
|---|---|---|---|---|
| G1 | 名称 | Input + 保存 | 1〜30 | オーナー編集。メンバーは読み取り |
| G2 | 参加者 | 行リスト | 表示名 + 役割「オーナー」「メンバー」。退会者は「退会したメンバー」 | 全員閲覧 |
| G3 | 除名 | Button 危険（行内） | 対象名とアクセス喪失を確認。登録ボトルは残す | オーナー |
| G4 | 招待 | 節 | 未使用リンクの期限と「無効にする」。「招待リンクを作る」 | オーナー |
| G5 | 移動 | 行 | 「自分のボトルを移す」 | 全員 |
| G6 | 履歴 | 行 | 「最近の変更」 | 全員 |
| G7 | 移譲 | 節 | 現メンバーから選び申請。24 時間。取消可。承諾までは旧オーナー | オーナー |
| G8 | 脱退 | Button 副 | 「共有セラーから出る」。確認文あり | メンバー。オーナーは他メンバーがいると不可 |
| G9 | 削除 | Button 危険 | 「共有セラーを削除」。名称入力確認 | オーナー |

脱退確認: 「追加したボトルと写真は共有セラーに残ります。自分の飲酒記録とノートは残ります。」「共有へ移したボトルは、脱退しても共有セラーに残ります。」

削除確認: セラー名入力。「全ボトルと写真が全員のセラーから消えます。各自の飲酒記録とノートは残ります。」

| 状況 | 表示 |

## フォームの保存先（`bottle-new` / `bottle-batch`）

| # | 要素 | 内容 |
|---|---|---|
| B0 | 保存先 | 先頭。「保存先：ふたりのセラー」。共有なら人アイコン +「参加者全員に表示されます」 |
| B0b | 変更 | 新規のみ。写真処理・アップロード中・保存中は不可。変更しても入力は保持 |
| B0c | 無効 | 共有が無効なら保存を止め、理由を出す。勝手に個人へ保存しない。テキストの退避は可 |

編集の保存先は読み取り専用。移動は独立操作。

## 詳細・削除・開栓後の文言

- 詳細: 「最終更新：○○・日時」。必要なら登録者。棚タイルに人物バッジは付けない
- 共有時のメモ欄ラベル: 「メモ（参加者に共有）」
- 記録節: 「自分の飲酒記録」「自分のノート」。件数は本人分のみ
- 開栓後シート: 「自分の飲酒記録をつける」「自分のノートを書く」。相手の開栓ではシート・振動・成功演出を出さない
- 共有削除: 「『○○』を共有セラーから削除しますか？参加者全員のセラーから消えます。各自の飲酒記録とノートは残ります。」主操作「全員のセラーから削除」

## ピッカー

`view=all&scope=accessible`。行に「自分のセラー」または共有名を出す。相手のノート件数・評価は出さない。

## 受け入れチェック

- [ ] 棚ヘッダー下にセラー選択行があり、個人は「自分のセラー / 自分だけ」、共有は名称と「N人」がテキストで分かる
- [ ] 選択シートに自分のセラー・共有・「セラーを共有する」または「共有設定」がある。切替で別セラーの棚が一瞬も出ない
- [ ] 共有作成は空の共有セラー。既存ボトルは移らない。1 人でも追加できる
- [ ] 招待は 1 リンク 1 人・24 時間。GET では参加しない。未ログインに在庫を出さない
- [ ] 参加確認に共有対象 / 非共有対象がある。参加後に個人ボトルは移らない
- [ ] 使用済 / 期限切は指定文言。別共有参加中は自動乗り換えしない
- [ ] 新規フォーム先頭に保存先。保存中は変更不可。共有無効時に個人へ黙って保存しない
- [ ] まとめて追加も全行の保存先を先頭で明示する
- [ ] 編集の保存先は読み取り専用。移動は確認（写真・メモ共有、脱退後も残る、記録は残る）
- [ ] 開栓後シートは操作本人だけ。相手受信では演出しない
- [ ] 詳細の記録節は「自分の」。相手の件数・評価を出さない
- [ ] 共有削除文と「全員のセラーから削除」がある
- [ ] メンバー脱退 / 除名 / 移譲 / セラー削除の確認が要素表どおり
- [ ] 競合時に入力を保持し、項目比較ができる。強制上書きが無い
- [ ] 権限喪失で共有データを隠し、個人セラーへ導く
- [ ] 360px / 文字 200% / ライト・ダークで選択行と確認文が読める
- [ ] 他人・非メンバーのセラー / ボトル / 写真は `not-found`
