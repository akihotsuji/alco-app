# プロダクト概要（仮称: alco-app）

## コンセプト

お酒に関する記録に特化した、スマートフォン向けWebアプリ（PWA）。
ワイン・蒸留酒を中心とした「少し大人向け」のユーザーが、日々の飲酒と手持ちのお酒を丁寧に記録・管理できる場所を提供する。

## 3つのコア機能

| 機能 | 概要 |
|---|---|
| 飲酒記録 | グラス単位で1日の飲酒量を記録。純アルコール量の自動計算、日/週/月のサマリー表示 |
| セラー管理 | 手持ちのボトル（ワイン・ウイスキー等）の在庫管理。写真・購入情報・開栓状態を記録 |
| テイスティングノート | 銘柄ごとの味わい・香り・評価の記録。写真添付、セラーや飲酒記録との連携 |

## 前提条件（確定事項）

- **形態**: モバイルアプリではなくWebアプリ。スマートフォンでの利用を第一に設計（モバイルファースト）。PWA対応（ホーム画面追加、アプリらしい見た目）まで行う。オフライン記録は当面スコープ外。
- **公開範囲**: まず個人用（自分＋家族・友人程度）として構築し、将来的な一般公開を視野に入れた設計にする（マルチユーザー前提のデータモデル・認証を最初から採用）。
- **招待制**: 採用しない。メール＋パスワードでサインアップできる。個人利用フェーズではアプリURLを公開しない運用でカバーする。
- **UIテーマ**: 端末・OSの外観設定（`prefers-color-scheme`）に追従する。ライト／ダークの両方を用意し、アプリ内のテーマ切替は持たない。
- **日付境界**: Asia/Tokyo。保存はUTC、表示・日次集計・休肝日判定はJSTのカレンダー日。
- **グラスプリセット**: 種類ごとの一般的な量・度数をデフォルト投入し、記録ごとに修正できる。数値は [01-requirements.md](01-requirements.md) 1.2、丸め・範囲は [features/alcohol-calculation.md](features/alcohol-calculation.md) を正とする。
- **予算**: インフラは無料枠での運用を基本とする（0円〜数百円/月）。
- **銘柄データ**: 手入力＋写真で管理。バーコードスキャンや外部DB連携は行わない（自分のマスターデータを育てる方針）。
- **開発体制**: AIエージェント主導の開発。オーナー（ユーザー）はほとんど実装せず、レビューと意思決定を担う。そのため保守性・一貫性・ドキュメント整備を特に重視する。

## スコープ外（当面）

- ネイティブモバイルアプリ / アプリストア申請
- オフラインでの記録（PWAの見た目対応まで）
- バーコードスキャン・外部酒類DB連携
- SNS的な共有機能・フォロー機能
- マーケティング・収益化
