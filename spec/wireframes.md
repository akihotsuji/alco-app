## 確定事項（1-02）

| 項目 | 決定 | 理由 |
|---|---|---|
| 記録入力 | **フルスクリーン**（`/logs/new`）。ボトムシートにしない | タブを隠す前提（1-01）。種類・量・保存が同時に見える。シートはキーボードで潰れる |
| FAB | **置かない** | 主アクションは画面内の大きなボタン。浮遊ボタンは誤タップしやすい |
| 1 タップ記録の undo | **トースト 5 秒**。確認ダイアログなし | 最短タップを守る。誤タップは undo で戻す |
| マイドリンクなしの最短 | **2 タップ**（種類 → 保存） | 種類選択で量・度数を自動投入。量チップは「変えるときだけ」 |
| その他 | 量・度数が空。保存は両方入力後だけ有効 | 要件 1.2 |
| 量チップ | 種類ごとの値は [alcohol-calculation.md](features/alcohol-calculation.md) | 1-06。箱図の 125 / 150 はワイン例 |
| レイアウト・メタファー | **一覧は行、詳細はプロパティ** | 壁紙デスクトップにしない。5 タブがナビの正 |

見た目は 1-03 の **ニューモーフィズム**（Win98 方針は破棄）。ゲーミフィケーションはスコア・押下・トーストまで。

## 共通シェル

```
┌──────────────────────────────────┐
│ タイトルバー（戻るがある画面は左）│  高さ 48px 以上
├──────────────────────────────────┤
│                                  │
│  コンテンツ（縦スクロール）        │
│                                  │
├──────────────────────────────────┤
│ ホーム  記録  セラー  ノート  設定 │  一覧・詳細のみ。作成・編集では消す
└──────────────────────────────────┘
```

- ヘッダーは色帯にしない（地と同じ。戻るは円ボタン）。OS のステータスバーは描かない
- タブは 5 つ。現在地をハイライト。ラベル＋アイコン（アイコン形状は 1-03）
- 作成・編集（`log-new` / `log-edit` / `mydrink-*` / `bottle-new|edit` / `note-new|edit`）はタブ非表示。左上は戻る
- 主アクションは画面につき **1 つ**。親指が届く下部に固定してよい

## 記録の最短タップ

| 状況 | 操作 | タップ数 |
|---|---|---|
| ホームにマイドリンクがある | そのチップを 1 回 | **1**（画面遷移なし。5 秒 undo） |
| マイドリンクなし・通常の種類 | ホーム「記録する」→ 種類 → 保存 | ホームから数えると **3**。入力画面内は **2** |
| 量や度数を変えたい | 種類のあと、量 or 度数を修正して保存 | +1 以上 |
| 種類「その他」 | 量と度数を手入力して保存 | 種類＋入力＋保存（2 タップでは終わらない） |

合格ライン: マイドリンクありは **1**。なしは入力画面内 **2**（種類デフォルトの量・度数のまま保存）。

## `log-new` 記録入力（UX 最優先）

画面 ID: `log-new`。タブなし。

**初回で見える情報**: 種類チップ、自動投入された量・度数、日時（いま）、下部の保存。  
**主アクション**: 保存する。  
**二次**: 戻る、量変更、度数変更、日時、メモ（折りたたみ）。

```
┌──────────────────────────────────┐
│ ←  記録する                       │
├──────────────────────────────────┤
│ 種類                              │
│ [ワイン*][ビール][ウイスキー][日本酒]│
│ [焼酎][カクテル][その他]           │  横スクロール可。選択は枠が凹む
│                                  │
│ 量                                │
│  125 ml                           │  種類デフォルト。大きい数字
│ [125*] [150] [375] [750] [手入力] │  グラス＋ボトル量チップ（正本は alcohol-calculation.md）
│                                  │
│ 度数                              │
│  12 %                             │
│ [ステッパー − / ＋ ]  または手入力 │
│                                  │
│ 日時  2026-09-04 13:05        ›  │  デフォルトは現在（JST）
│ メモ  任意                     ▼  │  初期は閉じる
├──────────────────────────────────┤
│ [          保存する          ]   │  固定。高さ 44px 以上
└──────────────────────────────────┘
```

キーボード表示時: 保存バーは **ビューポート下端に残す**（隠れない）。届かない場合は入力欄フォーカス中もバーを `sticky` し、必要なら画面をスクロールする。注記必須（実装 2-05 / 3-02）。

空状態: 種類未選択では保存を無効（通常はワイン等を初期選択してもよい。初期選択するなら「ワイン」）。**初期選択はワイン**（最初の種類）。ユーザーがすぐ保存できる。

エラー: 保存失敗は入力画面上の汎用メッセージ（「保存できませんでした。もう一度試してください」）。スタックや HTTP 詳細は出さない。

ローディング: 保存中はボタンを無効＋「保存中」。二重タップ防止。

`log-edit`: 同じレイアウト。見出しは「記録を編集」。下部に保存、その下にテキストリンク「削除」。削除は確認ダイアログ（はい / キャンセル）。1 タップ記録の undo とは別。

## `home` ホーム

**初回で見える情報**: 今日の杯数と純アルコール量、休肝バッジ（記録 0 のとき）、週の 7 マス、主ボタン「記録する」、マイドリンク（最大 4）。  
**主アクション**: 記録する（`log-new`）。  
**二次**: マイドリンク 1 タップ、週マスから `summary-week`、マイドリンク「管理」。

```
┌──────────────────────────────────┐
│ ホーム                            │
├──────────────────────────────────┤
│ ┌ 今日 ────────────────────────┐ │
│ │  2 杯          28 g           │ │  スコアウィンドウ（数字が大きくドーパミン）
│ │  休肝  （記録 0 のとき点灯）   │ │
│ │  月 火 水 木 金 土 日         │ │
│ │  ■  ■  □  ■  □  □  □      │ │  ■ = 記録あり。詳細は週サマリーへ
│ └──────────────────────────────┘ │
│                                  │
│ [         記録する         ]     │  主。primary 塗りの大きなボタン
│                                  │
│ マイドリンク                      │
│ [赤ラベル 125ml] [ハイボール]     │  1 タップで保存。遷移しない
│ [管理]                            │  → mydrink-list
├──────────────────────────────────┤
│ ホーム* 記録  セラー  ノート  設定 │
└──────────────────────────────────┘
```

メタファー: デスクトップ全面ではなく、**1 枚のステータスウィンドウ + ショートカット**。アイコンを壁紙に散らさない。

空状態（記録 0・マイドリンク 0）:

- スコアは 0 杯 / 0 g、休肝が点灯
- 「記録する」はそのまま主アクション
- マイドリンク欄: 「よく飲む一杯を登録すると、ここを 1 回タップで記録できます」＋「登録」（`mydrink-new`）

1 タップ記録後: 杯数と g が即座に増え、画面下にトースト「記録しました  [取り消す]」。5 秒で消える。取り消しで元の数字に戻す。

エラー: 1 タップ失敗時も同じ汎用文。数字は楽観更新しない（失敗したら増えない）。

ローディング: 初回スケルトンはスコア枠とボタンの外形だけ。

週サマリー（`summary-week`）: ホームの 7 マス領域をタップ。棒または同じ 7 マスの拡大＋日別合計。月は週画面から「今月」。箱図はホームと同じウィンドウ型。詳細チャートライブラリは Phase 3-06。

## `bottle-list` / `bottle-detail` セラー

### 一覧

**初回**: 検索、種類/ステータス、ボトル行（サムネ・銘柄・ステータス）。  
**主アクション**: 追加（`bottle-new`）。  
**二次**: 検索・絞り込み、行タップで詳細。

```
┌──────────────────────────────────┐
│ セラー                     [追加] │
├──────────────────────────────────┤
│ [ 名前・生産者で検索          ]   │
│ [種類▼]  [状態▼]                 │
│                                  │
│ ┌──── 行 ──────────────────┐   │
│ │ [写真] サンプル赤          未開栓│
│ │        2020 ・ フランス        │
│ └──────────────────────────┘   │
│ ┌──── 行 ──────────────────┐   │
│ │ [写真] サンプルモルト      開栓済│
│ └──────────────────────────┘   │
├──────────────────────────────────┤
│ ホーム  記録  セラー* ノート  設定 │
└──────────────────────────────────┘
```

メタファー: **フォルダの中身をリストで見る**（エクスプローラ）。グリッドのアイコンデスクトップにはしない。写真は行先頭のアイコン相当（48px 以上）。カードを Masonry しない。

空状態: 「ボトルはまだありません。1 本目を登録すると、ここに並びます」＋「ボトルを追加」。他ユーザーの在庫は出さない。

ローディング: 行のプレースホルダ 3 本。  
エラー: 汎用「読み込めませんでした」＋再試行。

### 詳細

**初回**: 写真、銘柄、ステータス、主な属性。  
**主アクション**: ステータス変更（未開栓 / 開栓済み / 飲み切り）。  
**二次**: 編集、ノート一覧セクション。

```
┌──────────────────────────────────┐
│ ←  サンプル赤              [編集] │
├──────────────────────────────────┤
│ [          写真          ]        │
│                                  │
│ ステータス  [未開栓|開栓済|飲み切] │  セグメント。確認は飲み切りだけでも可
│                                  │
│ 種類  ワイン                      │
│ 生産者  （属性は縦のプロパティ）   │
│ 産地 / 年 / 購入…                 │
│                                  │
│ ノート                            │
│  2026-08-01  ★4.5            ›  │  このボトルのみ。無ければ「ノートを書く」
│                                  │
│ （開栓→記録誘導は v1.x。置かない） │
├──────────────────────────────────┤
│ ホーム  記録  セラー* ノート  設定 │
└──────────────────────────────────┘
```

メタファー: ファイルのプロパティウィンドウ。重ねて複数ウィンドウは出さない。

## ゲーミフィケーション（配置でやること / やらないこと）

**やる（MVP）**

- ホームのスコアウィンドウ（杯数・g を大きく）
- 休肝の点灯（記録 0）
- 週 7 マス（埋まると気持ちよい。目標値は v1.x）
- ボタンの押下（凹む）。保存成功トースト
- 1 タップ記録の即時フィードバック

**やらない（MVP）**

- 経験値・レベル・ガチャ・ランキング・SNS 共有
- 毎回の紙吹雪・長いアニメ
- 開栓クエスト（v1.x の機能間連携）
- 他ユーザーとの比較

## 空・エラー・ローディング（横断）

| 状態 | 方針 |
|---|---|
| 空 | 説明 1 行 + その画面の主アクション。他ユーザーのサンプルは出さない |
| エラー | 汎用文 + 再試行。コードや URL を出さない |
| ローディング | 枠のスケルトン。無限スピナーだけにしない |
| 404 | [screens.md](screens.md) の `not-found`。「見つかりません」＋ホームへ |
