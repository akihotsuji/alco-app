## 2. データマップ

収集・生成する個人情報と、目的・保管・委託。クライアントだけの設定（外観、触感、動きを減らす、キャラ合成の既定、ラベル読み取りの ON/OFF、現在地を記録する）は端末の `localStorage` にあり、サーバーには送らない。

| 区分 | 項目 | 目的 | 保管 | 委託・国外 |
|---|---|---|---|---|
| アカウント | メール、パスワードハッシュ、表示名（任意）、作成・更新日時 | 登録、ログイン、設定表示 | D1 `user` / `account`（Better Auth） | Cloudflare（D1） |
| セッション | セッショントークン（httpOnly Cookie）、期限、IP、User-Agent | 認証維持、不正対策 | D1 `session` | Cloudflare。IP は `cf-connecting-ip` |
| 同意 | 規約・PP の版、同意日時 | 同意の記録 | D1 `legal_consents` | Cloudflare |
| 年齢確認 | 生年月日、確認日時 | 満 20 歳以上であることの確認。成功したときだけ保存する。API は確認済みかどうか（`ageVerified`）だけ返す | D1 `age_verifications` | Cloudflare |
| 飲酒記録 | 種類、量、度数、純アルコール量、日時、品名・品種・ヴィンテージ・生産国・生産者、メモ、店名、緯度経度（任意） | 記録と日次・週次・月次の集計 | D1 `drink_logs` | Cloudflare |
| マイドリンク | 名前、種類、量、度数 | 1 タップ記録 | D1 `my_drinks` | Cloudflare |
| セラー | 品名、種類、識別、購入・保管、価格、メモ、開栓日時 | 在庫管理 | D1 `bottles` | Cloudflare |
| ノート | 品名、種類、識別、飲んだ日、4 欄、評価 | テイスティング記録 | D1 `tasting_notes` | Cloudflare |
| 写真 | 加工後の画像 1 枚（向き補正・必要なら切り抜き・任意のキャラ合成済み）。元画像は残さない | 記録・棚・ノートの表示 | R2（非公開）+ D1 `photos` | Cloudflare |
| AI 利用回数 | ユーザーと JST 日ごとの回数 | 日次上限 | D1 `ai_usage` | Cloudflare |
| ラベル / 酒記録の推定 | 送信した画像と推定結果。**アプリ DB には残さない** | 空欄の候補。自動保存しない | 上流の処理中のみ | **Workers AI**（セラー・ノート）。酒記録は **Cloudflare AI Gateway 経由の外部モデル**（初期は Gemini）。モデル名は通常 UI に出さない |
| 位置情報 | 端末の緯度経度と手入力の店名 | 記録の場所。地図 URL は保存しない | D1（記録に紐付け）。取得は設定が ON のときだけ端末で 1 回 | 座標そのものは AI に送らない |
| バックアップ | D1 の定期エクスポート | 障害時の復元 | 非公開 R2。保持 14 日 | Cloudflare |
| 運用ログ | メソッドとパス。パスワード・Cookie・ボディは出さない | 障害調査・エラー通知 | Workers Logs。通知はウェブフック | Cloudflare ほか、オーナーが設定した通知先 |
| 端末設定 | テーマ、触感、動き、写真既定、認識 ON/OFF、現在地 ON/OFF、初回ガイド | UX | `localStorage` のみ | なし |

収集しないもの（この版）:

- 支払い情報
- 広告 ID、解析タグ、第三者のトラッキング Cookie
- 連絡先帳・写真ライブラリの一括アクセス（ユーザーが選んだ画像だけ）
- 他ユーザーへの公開プロフィール

## 3. 利用規約（草案）

**酒のしおり 利用規約**

版 `2026-09-10` / 施行日（草案）2026年9月10日

### 3.1 適用

本規約は、酒のしおり（`https://sake-shiori.com`。以下「本サービス」）の利用条件です。アカウントを作成した時点で、本規約に同意したものとします。

### 3.2 運営者

本サービスは個人が運営します。氏名・住所・連絡先はオーナー承認後に本ページへ掲載します。掲載までの開示請求は、承認後の連絡先へ行ってください。

### 3.3 サービス内容

本サービスは、飲酒記録、ボトルのセラー管理、テイスティングノートを、主にスマートフォン向けに提供します。会話するキャラクターや、飲酒を勧める案内は行いません。

### 3.4 利用資格

日本国内における酒類の年齢制限に合わせ、**満 20 歳未満の方は利用できません。** 登録後、専用の年齢確認画面で生年月日を入力し、サーバーが当日（Asia/Tokyo）時点で満 20 歳以上であることを確認するまで、記録・セラー・ノートなどの機能は使えません。確認の詳細は `spec/features/age-verification.md` を正とします。本規約への同意は、利用者が 20 歳以上であることの表明を含みます。

### 3.5 アカウント

メールアドレスとパスワードで登録します。招待コードはありません。認証情報は第三者に貸与・共有しないでください。セッションは Cookie で維持します（詳細はプライバシーポリシー）。

### 3.6 禁止事項

法令に反する利用、他者の権利侵害、不正アクセス、本サービスの妨害、未成年者への酒類の勧誘や提供に関する利用、他人になりすます行為、自動大量登録を禁止します。

### 3.7 ユーザーコンテンツと写真

記録・メモ・ノート・写真の著作権は、正当な権利者であるユーザーに残ります。本サービスは、表示・保管・バックアップに必要な範囲でのみ利用します。撮影対象（瓶ラベル等）について、ユーザーが必要な権利を有していることを前提とします。第三者の権利を侵害する写真をアップロードしてはなりません。

### 3.8 飲酒に関する注意

本サービスは飲酒を推奨しません。飲酒は利用者の判断と責任です。運転前の飲酒、体調を崩しての飲酒、法令で禁じられた飲酒を助長する目的では使えません。表示する純アルコール量は目安であり、医療上の助言ではありません。

### 3.9 免責

本サービスは個人運営のベストエフォートです。正確性、中断のなさ、データの完全な保全を保証しません。法令で認められる範囲で、利用により生じた損害について運営者は責任を負いません。バックアップ方針は運用ドキュメントに従います。

### 3.10 外部処理

ラベルや写真からの候補入力のため、設定が有効なときは画像を Cloudflare 上の AI（セラー・ノートは Workers AI、酒記録は Cloudflare 経由の外部モデル）へ送ります。自動では保存しません。候補が間違っていても登録は手入力で続けられます。

### 3.11 変更・終了

運営者は本サービスを変更または終了できます。本規約を変えるときは、本ページの版と施行日を更新します。重大な変更の再同意は、必要になったときに別途案内します。

### 3.12 準拠法

日本法に従います。紛争は、運営者の所在地を管轄する裁判所を第一審の合意管轄とします（所在地は承認後に確定）。

## 4. プライバシーポリシー（草案）

**酒のしおり プライバシーポリシー**

版 `2026-09-10` / 施行日（草案）2026年9月10日

個人情報の保護に関する法律（日本）に基づき、取り扱いを定めます。

### 4.1 事業者

本サービスの運営者（個人）。氏名・住所・連絡先メールはオーナー承認後に本ページへ掲載します。請求があれば、法令に従い遅滞なく開示します。

### 4.2 取得する情報と目的

2 章のデータマップのとおりです。目的は次に限ります。

- アカウントの作成・認証・設定表示
- 飲酒記録・セラー・ノートの保存と表示、集計
- 写真の保管と本人への配信（他ユーザーには見せない）
- ラベル等の候補入力（利用者が送ったときに限る）
- 不正利用の防止、障害対応、バックアップ
- 利用規約・本ポリシーへの同意の記録
- 満 20 歳以上であることの確認（生年月日は確認成功時のみ保管）

販売、広告配信、他ユーザーへの公開には使いません。

### 4.3 飲酒記録（健康に隣接するデータ）

杯数、量、度数、日時、場所、メモは、利用者が任意に入れる **生活記録** です。診療録や健康診断の結果ではありません。診断・治療・保険査定の目的では利用しません。要配慮個人情報としての取り扱いは専門家の確認を待ち、確定したら本ポリシーを更新します。

### 4.4 写真

端末内で向き補正・リサイズ・（任意の）キャラクター合成、セラーは背景除去を行い、加工後の 1 枚だけを保存します。元画像はサーバーに残しません。配信はログインした本人向けの API のみです。R2 バケットは非公開です。

### 4.5 位置情報

設定「現在地を記録する」（既定 ON）が有効なときだけ、新規の飲酒記録で端末の位置を 1 回取得できます。店名は手入力です。地図の URL は保存しません。OFF にすると新規記録では位置を要求しません。保存済みの店名・座標は、OFF にしただけでは消しません。

### 4.6 AI への送信

設定が ON のとき、ラベルや酒の写真を次へ送り、候補だけ返します。結果は自動保存しません。

- セラー・ノート: Cloudflare Workers AI
- 酒記録: Cloudflare AI Gateway 経由の外部モデル（初期設定は Gemini）

プロンプトやモデル名をクライアントから指定することはできません。日次の回数上限があります。Gateway の本文ログは、運営者が明示的に ON にしたときだけ取ります（既定 OFF）。

### 4.7 国外への取扱い

インフラは Cloudflare です（Workers、D1、R2、Workers AI、AI Gateway）。データは日本国外のサーバで処理されることがあります。委託先との契約と、公開されているセキュリティ機能の範囲で保護します。

### 4.8 Cookie

ログイン維持のため、httpOnly / Secure（HTTPS）/ SameSite=Lax のセッション Cookie を使います。広告・解析用の第三者 Cookie は置きません。そのため Cookie 同意バナーは出しません。

### 4.9 第三者提供

法令に基づく場合を除き、個人情報を第三者に販売・提供しません。Cloudflare および（酒記録の推定時）その先のモデル提供者は、サービス提供のための委託先です。

### 4.10 保管期間

アカウントがある間、サービス提供に必要なデータを保管します。未紐付け写真は作成から 24 時間で削除します。D1 バックアップは約 14 日です。アカウント削除の画面は未実装です。削除を希望する場合は、本ポリシー掲載の連絡先（承認後）へ請求してください。請求が確認できたときは、法令とバックアップの保持期間の範囲で、D1 と R2 から削除します。

### 4.11 開示・訂正・利用停止

本人確認のうえで、法令に定める開示・訂正・利用停止等に対応します。請求先は承認後の連絡先です。

### 4.12 安全管理

通信は HTTPS です。パスワードは Better Auth のハッシュのみを保存し、アプリから読み出しません。API はセッションのユーザー ID でデータを区切ります。他ユーザーの記録・写真にはアクセスできません。

### 4.13 改定

本ポリシーを変えるときは、本ページの版と施行日を更新します。重大な変更の再同意手順は、必要になったときに追加します。
